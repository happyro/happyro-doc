# 安装

HappyRO 提供四种安装方式，请根据运行环境选择对应指南：

- [Docker](/installation/docker)：使用 Docker Compose 运行数据库、服务端和 Gateway。
- [Linux](/installation/linux)：在 Linux 物理机上使用 Bash、systemd 和 Makefile 部署。
- [macOS](/installation/macos)：在 Linux 虚拟机或远程 Linux 主机上部署，再从 macOS 浏览器访问。
- [Windows](/installation/windows)：使用 WSL2 运行 Linux 部署环境。
