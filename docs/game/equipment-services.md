## 两种附魔的区别

两种附魔都从 NPC 开始：专用窗口附魔打开统一的装备附魔界面；NPC 对话附魔通过各 NPC 的对话选项完成操作。

附魔效果取决于装备与配方，不取决于操作界面。在同一装备上附加相同附魔时，效果相同；不同配方的属性范围、随机或指定方式、附魔位置、升级与重置规则，以及失败后果可能不同，以对应服务的说明为准。

## 如何查找自己的装备

使用浏览器的页面搜索查找装备 ID，避免同名或相似名称混淆；游戏图鉴也支持 ID 搜索。装备不在清单中时，不要仅凭“能显示名称”判断是否通过资料与穿戴核验。已列出的装备也必须由满足条件的角色穿戴，99 级测试角色不能因此穿上要求 190、220 或 240 级的装备。
