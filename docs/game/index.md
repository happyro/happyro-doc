## 如何使用本指南

第一次进入游戏，按「登录与角色 → 界面与操作 → 背包与装备 → 快捷键与技能」阅读。需要和朋友互动时，按对应专题完成双方步骤；交易、好友邀请、入队和邮件各有独立的确认过程。

配图来自当前源码构建的实际游戏界面，以浏览器模拟的平板横屏为主，手机竖屏与电脑补充布局或操作差异。示例角色为剑士罗安和铁匠玛雅；职业、技能与服务器开放权限决定你实际能使用的功能。管理员专属操作会单独说明，不作为普通玩家默认能力。

![平板主菜单中的玩家功能入口](/images/game/controls/tablet-menu.png)

菜单内的「人物」「状态」「素质」见[界面与操作](/game/controls#人物、状态与素质)；「我的摊位」见[交易与摆摊](/game/trading#查看与关闭自己的摊位)。仓库和 NPC 服务需要先与相应 NPC 交互，并非主菜单中的常驻按钮。
