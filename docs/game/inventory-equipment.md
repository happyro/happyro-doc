# 背包与装备

电脑从状态栏菜单进入，或用 Alt + E 打开背包、Alt + Q 打开装备；手机和平板从「菜单 → 背包／装备」进入。快捷道具绑定见[快捷键与技能](/game/shortcuts)。

![平板背包的分类列表、物品说明和操作栏](/images/game/inventory/tablet-inventory.png)

## 查看和使用物品

背包按类型筛选，点击物品查看名称、数量、重量和说明。手机／平板在说明下方显示当前可用的「使用」「穿戴／卸下」「镶嵌卡片」「设置快捷键」和「丢弃」等操作；不是每件物品都有全部操作。

使用、丢弃和镶嵌都有实际物品后果，确认前核对名称、数量及目标。已穿戴物品不能直接丢弃；不可用时先检查职业、等级、地图及当前角色状态。图鉴说明只供查询，是否成功以服务器回包为准。

物品的新获得标记与当前背包条目对应；刷新或移除物品后，以最新数量和穿戴状态为准。快捷栏绑定不会复制物品，也不会解除使用条件。

物品说明与装备比较中的地点链接可打开地图标点，魔物链接可打开图鉴，帮助和物品引用可打开参考阅读器。只查看后关闭会恢复来源与阅读位置；开始寻路或发出传送请求后不再自动返回。详见[说明链接与帮助](/game/text-links/)。

### 电脑上的背包操作

电脑背包按分类页签显示物品。右键查看物品说明；可使用的物品或装备通过双击操作，也可将支持的条目拖到快捷栏、仓库或服务窗口。拖放出现数量选择时，核对来源和目标再确认。

![桌面背包与场景，拖放操作从实际物品格开始](/images/game/inventory/desktop-inventory.png)

## 选择和更换装备

手机／平板装备窗口提供「装备」「时装」「影子」「属性」分类。选择部位后查看说明；空部位点「选择装备」，已有装备点「更换」或「卸下」。没有初步候选时选择按钮置灰。候选来自当前背包，选定后再确认操作；背包没有该部位的候选时不会凭空创建装备。

普通装备和影子装备分开管理。能否双持、某件武器能放在哪只手、是否需要先卸下其他部位，都由服务器按当前职业、技能和装备规则判断。

![平板装备部位与详情](/images/game/inventory/tablet-equipment.png)

更换列表先排除已穿戴、未鉴定、损坏或部位不匹配的物品，再请求服务器检查职业、等级、性别等穿戴资格。加载时等待列表结果；请求失败时阅读右侧原因并使用底栏「重试」。没有可用候选时不能确认穿戴，不会自动替换为其他部位。

![装备选择弹窗显示通过穿戴资格检查的候选](/images/game/inventory/tablet-equipment-picker.png)

## 转职与技能变化

转职、洗点或技能变更可能改变装备资格，尤其是左手武器及影子左手装备。失去相应资格时，服务器会清理不合法穿戴和预备装备配置，并同步背包／装备显示；不需要重新登录才能看到变化。合法盾牌和右手装备仍按自身规则保留。

看到装备不再穿戴时，先查看当前职业和技能要求，而不是反复装备或把旧窗口截图当作当前状态。若界面与实际状态仍不一致，提供变更前后职业、技能、物品 ID 和操作步骤，见[反馈方式](/community/contact)。

## 仓库与手推车

仓库须通过对应 NPC 或可用功能打开；手推车还需要当前职业和技能条件。在窗口中选定物品、方向及数量后提交，等待服务器更新。个人仓库、公会仓库、背包和手推车是不同容器，不能把列表切换当成物品转移。

卸下手推车与转移物品是不同操作，卸下不会自动把车内物品放入背包。骑乘与随行的租用和解除见[职业外观与骑乘](/game/appearance)。

详细存取步骤见[仓库、手推车与银行](/game/storage-bank)；鉴定、卡片、强化与附魔入口见[NPC 对话与商店](/game/npc-shops#其他服务)。

## 装备升阶

通过提供升阶服务的 NPC 打开界面。手机和平板使用与精炼相同的装备分类、子类、搜索和两列装备列表；选择装备后查看材料、持有数量、费用、成功率及失败风险。手机竖屏上方为详情，下方为装备列表和筛选，平板横竖屏均为左右双栏。

底栏选择材料方案、填写祝福次数，再点“下一步”核对后确认。不同材料方案的数量和失败风险可能不同，基础成功率相同；祝福次数才会增加成功率，达到 100% 时无需再添加。无法升阶的装备会显示提示。升阶成功后精炼等级归零。全服概率由[精炼/升阶设置](/admin/game-settings#精炼-升阶)控制。

通过资料与穿戴核验的装备列表及加工条件见[装备升阶](/game/equipment-grade)。
