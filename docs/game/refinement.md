# 装备精炼

精炼提升装备的精炼等级，和附魔、装备升阶是三套不同的服务。精炼不会把装备变成阶级装备；装备升阶成功后，精炼等级会归零。不同装备的精炼上限、材料、费用、成功率和失败结果以当前精炼窗口显示为准。

## 打开精炼窗口

与提供精炼服务的 NPC 对话，结束介绍后等待精炼窗口打开。例如，普隆德拉室内 `prt_in` 的忽克连提供精炼服务。NPC 的地图位置也可以从[图鉴与冒险工具](/game/adventure-tools)查找。

## 选择装备和材料

电脑将背包中的目标装备拖入窗口；手机和平板从装备列表中选择目标。选择后核对装备名称、当前精炼等级、所需材料、持有数量、Zeny 和成功率，再继续下一步。

手机和平板使用与装备选择相同的分类、子类、搜索和列表布局。窗口中的装备可选状态只表示当前服务接受该装备，角色能否穿戴仍由职业、等级、性别和其他条件决定。

## 确认风险

确认前阅读当前窗口显示的失败结果。保护材料是否可用、失败时是否损坏或降级，都以所选装备和材料方案的实际提示为准。材料或 Zeny 不足时先补齐，再重新选择装备和方案。

显示成功率不等于已经完成精炼；只有确认操作成功并收到结果提示后，精炼等级和材料才会更新。

## 精炼与其他装备服务

| 服务 | 作用 | 说明 |
| --- | --- | --- |
| 精炼 | 提升 `+0`、`+1` 等精炼等级 | 使用精炼 NPC 和精炼材料 |
| 附魔 | 为装备增加附加属性 | 分为[专用窗口附魔](/game/window-enchantment)和[NPC 对话附魔](/game/npc-enchantment) |
| 升阶 | 提升 D、C、B、A 阶级 | 见[装备升阶](/game/equipment-grade)，成功后精炼等级归零 |

冒险工具中的“游戏设置 → 精炼/升阶”可以调整全服精炼倍率和必定成功开关；详细范围见[管理后台的精炼／升阶设置](/admin/game-settings#精炼-升阶)。
