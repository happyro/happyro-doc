# 图鉴与冒险工具

电脑点击“冒险工具”或按 Alt + F；手机和平板从“菜单 → 冒险工具”进入。查询资料与权限允许的维护功能集中在这里。

以下按地图、魔物、物品、NPC、角色和设置六个页签展示真实界面。截图使用 99 级剑士罗安；权限和职业决定实际可用按钮，长详情需要在面板内滚动。

## 地图图鉴

查看中文地图名、地图代码、缩略图、当前角色和 NPC 位置。可搜索地图、预览路线，并对当前地图目标自动寻路。跨地图路线预览不等于自动完成传送或 NPC 交互；传送需要服务器开放权限。

![罗安在平板上查看普隆德拉地图与 NPC 列表](/images/game/adventure/tablet-adventure-map.png)

平板分栏展示地图列表、地图预览与 NPC 列表；NPC 列表显示名称，位置在地图标记和详情中查看。地图支持按当前中文名称或地图代码搜索，例如「普隆德拉」或 `prontera`；不需要先知道中文译名。

在地图预览上滚动会滚动外层详情；NPC 列表先内部滚动，到顶或到底后继续滚动外层。有刷新记录的地图显示「地图魔物 ↓」，点击直接定位到魔物区域；没有记录时入口置灰。`new_event`、`pprontera` 没有配置玩家入口，不列入玩家地图列表，后台资料查询仍可保留这些资源。

资料说明中的地点、帮助和物品引用可以直接点击，行为见[说明链接与帮助](/game/text-links/)。物品页中的链接在同一窗口切换地图或魔物页，切回「物品」可恢复原资料；关闭会退出整个冒险工具。从背包、任务或参考阅读器打开的地图，则在仅查看后关闭时恢复外部来源。

## 魔物图鉴

![波利的资料、掉落和出现地图](/images/overview/happyro-codex.png)

![平板魔物图鉴中的波利属性、掉落与出现地图](/images/game/adventure/tablet-adventure-monster.png)

按名称或 ID 搜索，可筛选当前地图及类型。详情包含等级、HP、种族、属性、经验、掉落物品和出现地图。召唤、地图传送只在相应能力开放时可用；不能从按钮是否存在推断普通账号拥有权限。

## NPC 图鉴

查询静态 NPC 的中文名称、外观、地图和坐标，再结合地图寻找入口。室内、任务触发或动态生成的 NPC 不一定能直接用直线走到；转职任务应同时参考[职业攻略](/strategy/job-change/)。

![搜索卡普拉并查看 NPC 外观、地图标记与坐标](/images/game/adventure/tablet-adventure-npc.png)

## 物品图鉴

支持中文名、英文名或 ID 等查询，显示图标、类型、重量、价格与说明。服务端效果与客户端资料可能有不同来源，实际使用条件由服务器决定。

![红色药水的物品资料、说明与查询列表](/images/game/adventure/tablet-adventure-item.png)

## 角色与游戏设置

角色属性调整、物品和 Zeny 发放、状态恢复、地图传送和倍率修改由服务端校验权限。服主管理流程见[账号与角色](/admin/accounts-characters)、[运营发放](/admin/grants)和[游戏设置](/admin/game-settings)。

## 名称与刷新范围

魔物中文名称会与场景、任务及后台目录同步审校；遇到同名或不同副本变体时用魔物 ID 区分。出现地图和刷新位置来自服务器配置，不代表对应坐标当前一定有活着的魔物。修改中文名不会改变属性、掉落概率或召唤权限。

## 桌面世界地图与导航

电脑状态栏的「世界地图」用于查看区域关系。用顶部下拉框切换世界区域，悬停地点查看地图名称与资料；点击地点打开导航地图。「魔物」选项显示相应资料，不代表该位置当前一定有存活目标。

![桌面世界地图与区域选择](/images/game/adventure/desktop-world-map.png)

独立「导航」入口可按名称或地图代码搜索，选择类型及「全世界／当前地图」缩小范围。选中结果后查看位置，再用「开始寻路」前往当前地图目标；「停止寻路」中止当前路线。传送按钮仍受服务器权限限制。

![桌面导航搜索地图代码 prontera](/images/game/adventure/desktop-navigation.png)

手机和平板使用冒险工具中的地图、NPC 和魔物页完成查询；不要根据桌面窗口的位置寻找触屏入口。

## 精炼/升阶设置

在“游戏设置 → 精炼/升阶”分别设置精炼和升阶的成功率倍率、必定成功开关。两类操作独立生效，倍率输入 1 表示原始概率。启用必定成功仍须满足装备与精炼等级要求并消耗材料和 Zeny；升阶成功后精炼等级归零。详细计算方式见[游戏设置](/admin/game-settings#精炼-升阶)。
