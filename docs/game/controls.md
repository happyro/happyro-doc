# 界面与操作

![罗安在电脑、平板横屏与手机竖屏中的实际界面](/images/overview/happyro-three-devices.png)

## 电脑桌面

使用鼠标点击地图移动，点击 NPC 交谈，点击地面物品拾取。窗口入口位于状态栏菜单，技能与道具可以绑定快捷栏。常用窗口的快捷键也会显示在入口提示中。

| 快捷键 | 窗口 |
| --- | --- |
| Alt + E | 背包 |
| Alt + Q | 装备 |
| Alt + S | 技能 |
| Alt + Z | 队伍 |
| Alt + G | 公会 |
| Alt + U | 任务 |
| Alt + F | 冒险工具 |
| Esc | 选项 |

浏览器或操作系统可能截获快捷键；无法打开时使用游戏内按钮。

在场景空白处按住鼠标右键左右拖动可旋转镜头，按住 Shift 并右键上下拖动可调整俯仰，滚轮调整远近；Ctrl 加右键上下拖动也可缩放。正在选择技能目标时，滚轮改为调整技能等级，先取消施法再调整镜头。右键双击重置朝向，Ctrl 加右键双击重置远近。

右下角战斗按钮上方常驻「表情、坐下／站起、骑乘／下骑」。无骑乘能力的职业不显示骑乘按钮，其余按钮靠右排列；支持骑乘的职业即使缺少技能或费用也显示入口，点击提示具体条件。坐下和表情仍需相应基础技能。点击小地图可打开冒险工具地图页。

## 手机和平板

左上角显示角色信息与菜单、任务和镜头入口；右上角显示地图和坐标。手机竖屏状态图标位于右侧，按地图与右下操作区之间的高度自动换列；手机横屏位于左上角色信息右侧并向右换行，说明框显示在图标下方；平板横竖屏均在右侧显示。状态仅显示原始图标，点击在图标旁显示半透明黑底说明，再次点击或点外部收起，不打开状态弹窗。右下角提供战斗控制与六格分页快捷栏，聊天预览可以收起。

| 操作 | 使用方法 |
| --- | --- |
| 移动 | 在画面左侧场景区域按住并拖动，松手停止，不显示摇杆 |
| NPC 交谈、地面拾取 | 点击目标，角色靠近后执行 |
| 攻击一只魔物 | 点击魔物，靠近并攻击；未启用自动战斗时不会自动寻找下一只 |
| 使用指向性技能 | 点击快捷技能后再点击目标；需要时先靠近 |
| 取消技能选择 | 点击“取消施法”；移动或切换快捷栏页码不取消选择 |
| 坐下、表情与骑乘 | 点击右下角「动作」展开表情、坐下／站起和骑乘／下骑；点击「取消」收起；骑乘条件与桌面端相同 |
| 用治愈术攻击魔物 | 选择治愈术后点击不死属性魔物，无需 Shift |
| 选择其他玩家 | 点击角色后使用私聊、装备、好友、交易；点击左侧「取消」清除选择 |
| 使用道具 | 点击已配置的快捷道具，或从背包使用 |

移动与技能点击可以配合使用。自动战斗期间点击魔物会临时指定攻击目标，之后继续按配置寻找目标。

角色死亡时会弹出返回保存点的操作；持有原地复活之证且地图允许时，可确认消耗道具复活。选择等待救援后，可从右下角独立的「返回 / 复活」按钮重新打开；按钮出现时隐藏战斗信息。

登录、选服及角色选择阶段的提示、错误和确认弹窗使用与注册弹窗一致的亮色样式；进入游戏后使用暗色弹窗。移动端常驻一排「动作／取消」「战斗设置」「自动战斗／停止战斗」，下方保留快捷栏分页和「快捷键」。点击自己的角色不展开动作菜单；使用「动作」按钮。自身、宠物及其他角色动作独立显示；展开时隐藏战斗提示，取消后恢复，不带外层边框和背景，按钮与下方战斗工具栏等高。展开动作会结束正在运行的自动战斗，避免战斗自动选怪把动作菜单收起；使用后需要手动重新开启自动战斗。

## 右下角上下文操作

战斗信息区域只显示文字，不放按钮。点击传送阵显示黄色「进入传送阵」「取消」；选择玩家、摊位、宠物、佣兵或生命体时，显示各自独立的操作按钮。按钮出现时隐藏战斗信息，清除选择后恢复。佣兵和生命体的「主动／被动」均为黄色，以文字区分状态。

NPC 对话导航的「打开地图」「取消」同样独立显示；桌面、手机和平板均放在右下角战斗操作区左侧，与战斗按钮同一行。完整流程见[地图与目标链接](/game/text-links/navigation)。

## 横竖屏与菜单

手机和平板都可横竖屏游玩。平板及手机横屏通常以左右分栏呈现列表和说明；手机竖屏按功能使用上下布局，操作按钮集中在底栏。两种布局共享数据，不需要重新配置角色。

![同一狂击技能在平板与手机上的布局](/images/overview/happyro-responsive-skills.png)

镜头设置从“镜头”入口调整；添加到主屏幕可减少浏览器工具栏占用，见 [PWA](/game/pwa)。

## 功能范围与限制

常用背包、装备、素质、技能、社交、任务、邮件、银行、仓库及商店已有触屏布局；是否可用还取决于角色、技能和服务器权限。自动寻路仅支持当前地图，战斗不支持全地图巡逻。

聊天室、部分装备／技能附加窗口，以及生命体／佣兵的部分技能详情和直接指令仍有待完善分支。异常反馈请附设备、浏览器、横竖屏及具体操作步骤，见[联系与反馈](/community/contact)。

## 人物、状态与素质

手机和平板从菜单分别打开「人物」「状态」「素质」。人物查看当前角色信息；状态查看正在生效的状态及说明；素质用于分配属性点。电脑从人物／素质窗口查看对应内容。

![平板素质面板，左侧预加点，右侧查看相关数值](/images/game/controls/tablet-attributes.png)

素质加点先在左侧调整预加值，再核对剩余点数，点击「确认」提交。「清除预加点」只撤销尚未提交的计划。「重置素质点」是另一个操作，需要服务器允许并再次确认；不能把清除草稿当成洗点。四转素质仅适用于满足条件的职业。

![平板状态说明](/images/game/controls/tablet-status.png)

## 坐下、站起与表情

手机和平板点击右下角「动作」，再选择坐下或表情；坐下后相应入口变为站起。电脑使用右下角对应按钮。打开表情列表后点击所需表情，发送结果在角色上方显示；坐下和表情需要已学习相应基础技能。

坐下用于休息，不等于退出游戏或开启自动恢复。准备移动、战斗或办理 NPC 服务前先站起。动作入口还会按职业提供骑乘等功能，见[职业外观与骑乘](/game/appearance)。
