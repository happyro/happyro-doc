# 公会与氏族

手机和平板从“菜单 → 社交 → 公会”查看公会资料、成员和公告；电脑使用对应的公会窗口。公会操作由服务端按当前角色身份和权限检查，看到按钮不代表当前角色一定可以执行操作。

## 公会资料与成员

首次打开公会概况会同步成员列表，并显示总人数和在线人数。执行成员管理前先刷新资料，核对角色名称、职位和在线状态。

## 职位与权限

会长可以调整成员职位和公会权限。仓库权限包括存入、取出等操作；权限变更后在线成员会刷新状态，已打开但不再有权限的仓库会自动关闭。非会长看到的权限为禁用状态，表示实际权限而不是可编辑选项。

## 公会仓库与记录

在提供公会仓库服务的 NPC 处打开仓库。公会仓库与个人仓库、手推车分开，存取受到成员权限和仓库锁定状态限制。仓库记录窗口可以分页查看最近的物品变更；记录加载失败时按窗口提示重试。

## 退出、驱逐与解散

退出、驱逐、转交会长和解散都是实际的公会状态变更，不是关闭窗口。会长不能直接退出公会；需要先将会长转交给其他成员。解散前确认目标公会和成员状态，操作完成后重新打开公会资料确认结果。

## 公会与氏族的区别

公会通过公会窗口管理成员、职位、权限和仓库；氏族是独立系统，需要通过对应 NPC 加入。聊天中的公会频道和氏族频道分别只对所属组织成员生效。

攻城入口、开放时段和城堡管理见[攻城战](/game/guild-war)。
