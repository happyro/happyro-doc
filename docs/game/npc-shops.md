# NPC 对话与商店

点击 NPC 后，角色会靠近并开始交谈。先读对话，再选择服务；地图中的 NPC 标记只帮助定位，不会替你完成对话或任务。

## 对话、选项与输入

对话可能要求点击「下一步」、选择选项、输入文字或数字。手机和平板在对话面板内完成操作；电脑使用对应对话窗口。

- 选项会改变剧情或进入服务，确认名称后再点击。
- 电脑 NPC 菜单先选中选项，再点击确认；手机和平板直接点选按钮。文字与数字输入按 NPC 的要求填写；不要把物品名称填入只接受数量的输入框。
- 正常结束对话后再移动或打开其他交互；长对话可在正文区域滚动。
- 地点和帮助链接可以在对话中点击，详见[地图与目标链接](/game/text-links/navigation)。

## 购买物品

1. 与商店 NPC 交谈，选择购买。
2. 在商品列表选择物品，阅读说明和价格。
3. 点击加入箭头，填写数量并确认，将物品放入「待购买物品」。
4. 核对清单、合计和余额，点击「购买」。成功后查看背包数量和余额。

加入清单还没有扣款。反向箭头可移回商品；「清空」清除本次选择。特别商店可能使用指定道具或点数，按窗口显示的货币核对。

![购买前核对商品、数量、单价和合计](/images/game/npc/tablet-shop-buy.png)

## 出售物品

选择 NPC 的出售服务，在「可出售物品」中选择条目并加入「待出售物品」，核对数量及合计后点击「出售」。这会实际移除物品，不是转移到仓库；出售前确认没有把需要保留的装备或材料加入清单。

装备状态、交易限制、负重和持有数量可能使条目不可选或让提交失败。更换筛选条件不会自动完成交易。

![出售前核对待出售清单](/images/game/npc/tablet-shop-sell.png)

## 其他服务

| 服务 | 操作与需要核对的内容 |
| --- | --- |
| 仓库、保存点和传送 | 按 NPC 选项确认费用；仓库操作见[仓库、手推车与银行](/game/storage-bank) |
| 鉴定 | 使用放大镜或物品鉴定技能，选择未鉴定装备并确认；鉴定后再核对说明与穿戴资格 |
| 镶嵌卡片 | 从背包选择卡片，打开适用装备列表，核对装备和插槽后确认 |
| 分离卡片 | 在绵绵岛找杰勒米（铠甲、鞋子、披风和上段头饰）或理查特（武器和盾牌），选择已装备且有普通卡片的部位，再选择费用或润滑剂并确认风险 |
| 精炼／装备升阶 | 在服务打开的窗口选择装备、材料及可用保护选项，点击「下一步」核对费用、概率和风险，再确认 |
| 附魔 | 选择装备和附魔方式，检查费用、材料及可能结果，点击「下一步」核对后确认；重置会清除对应附魔 |
| 制造、合成与材料选择 | 按服务要求选择材料及数量，加入材料后核对清单，再提交 |

### 桌面与触屏的精炼操作

例如普隆德拉室内 `prt_in` 63,60 的忽克连提供精炼服务。先结束介绍对话，等待精炼窗口打开；手机和平板从候选列表选择装备，电脑把背包中的目标装备拖入精炼窗口，再选择材料并核对费用。

![桌面将装备拖入精炼窗口后查看所需材料](/images/game/npc/desktop-refinement.png)

未准备材料时先关闭窗口补齐；不要把显示的成功率当作已经完成精炼。保护材料是否可用、失败会损坏还是降级，都按所选装备和当前服务显示核对。

这些窗口由相应 NPC、技能或物品触发，不是主菜单里的通用免费服务。具体配方、职业要求、费用和成功率以当前服务显示为准；没有相应入口时，不能通过打开指南解锁功能。

### 分离已插入的卡片

绵绵岛的杰勒米和理查特分别处理不同部位。杰勒米处理铠甲、鞋子、披风和上段头饰；理查特处理左手和右手装备，包括武器与盾牌。先装备目标物品，再在对应 NPC 的部位菜单中选择它；没有装备或没有可分离的普通卡片时，服务会停止并提示原因。带有附魔的装备还可能在分离时失去附魔效果。

普通分离费用为 1,000,000 Zeny，也可以使用高级或普通润滑剂。无论选择哪种方式，都可能损坏装备或卡片，精炼等级也可能丢失；确认前请先阅读当前窗口的风险提示。分离结果以窗口显示为准，损坏的装备或卡片无法恢复。

### 装备升阶

装备升阶提升的是 D、C、B、A 阶级，与 +9、+10 等精炼等级不同。普隆德拉升阶所 `grademk` 34,184 的史拉托斯提供此服务。

电脑将背包中的装备拖入窗口；手机和平板从列表选择装备。选择材料方案与祝福次数，核对成功率、消耗及损毁风险后确认。升阶成功后精炼等级归零；失败结果取决于所选方案。材料或 Zeny 不足时先补齐，再重新选择。

通过资料与穿戴核验的装备清单、NPC 位置与条件见[专用窗口附魔](/game/window-enchantment)、[NPC 对话附魔](/game/npc-enchantment)和[装备升阶](/game/equipment-grade)。

## 桌面商城入口

右上角显示商城入口时，点击可查看当前服务器提供的商品与点数余额。商品需要加入购买列表，核对数量、点数类型及总额后再购买；加入列表不会立即扣款。

![桌面商城，本机示例没有配置商品](/images/game/npc/desktop-cash-shop.png)

商城与消耗 Zeny 的 NPC 商店不同。没有商品时无法购买；是否提供点数和充值渠道由部署方决定，界面中的「充值」按钮不代表 HappyRO 已提供支付服务。
