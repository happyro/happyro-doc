# 仓库、手推车与银行

物品在背包、仓库和手推车之间转移；Zeny 在角色余额和银行之间存取。这些操作都以服务器确认后的数量为准。

## 打开仓库

1. 找到提供仓库服务的卡普拉员工或其他 NPC，点击交谈。
2. 选择仓库服务，按对话确认费用和条件。
3. 仓库打开后，在窗口内选择物品来源和存取方向。
4. 选中物品，填写数量，点击「确认存入」或「确认取出」。检查两边数量更新后再继续。

手机和平板可以使用分类、子类和搜索缩小列表，数量栏提供 MIN、MAX 和增减按钮。电脑也可用对应容器的拖放操作；数量弹窗出现时核对后确认。

仓库容量、角色负重和物品限制都可能阻止转移。公会仓库需要通过其服务入口打开，并满足公会权限；个人仓库与公会仓库不能混用。

## 手推车

商人系角色需要学习手推车技能并租用手推车。可以向卡普拉员工申请；如果服务器开放角色维护权限，也可从「冒险工具 → 角色 → 骑乘与随行」租用。

1. 打开「菜单 → 手推车」。
2. 选择「存入」将背包物品放入车内，选择「取出」将车内物品放回背包。
3. 选中物品并填写数量，核对目标容器后确认。

![玛雅的手推车物品和存取操作](/images/game/storage/tablet-cart.png)

未租用时会显示相应提示；仅学习技能或拥有车内物品不代表已经租用。卸下手推车会要求确认，车内物品保留，不会自动回到背包。重新使用时需要再次租用。

摆摊出售的商品应先放进手推车，具体步骤见[交易与摆摊](/game/trading)。

## 银行存取 Zeny

手机和平板从「菜单 → 银行」进入，电脑通过银行入口打开。

![角色余额与银行余额分别显示，箭头用于存入和取出](/images/game/storage/tablet-bank.png)

1. 核对「当前余额」和「银行余额」。
2. 点击向银行方向的箭头存入，或反向箭头取出。
3. 输入金额；MIN、MAX 分别填写当前允许的最小、最大金额。
4. 确认后等待余额更新。金额不足或当前状态不允许时，按提示处理。

银行只存取 Zeny，不保存物品。银行中的余额不会因为打开商店就自动转为角色身上的现金，购买、邮费和摆摊预算前应检查角色余额。
