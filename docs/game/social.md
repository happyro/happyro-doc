# 聊天与社交

手机和平板从“菜单 → 聊天”查看消息，从“菜单 → 社交”管理好友、队伍和公会。电脑使用聊天框及对应的好友、队伍、公会窗口。

## 选择发送频道

移动端选择的消息分类也决定发送目标：附近、私聊、队伍、公会或氏族。队伍、公会、氏族发言需要当前角色属于相应组织。

“全部”“系统”“战斗”用于阅读，不能直接输入发送；先切换到可发言频道。消息旁的回复入口可进入对应会话，不能把浏览全部消息理解为默认向附近发送。

## 私聊

选择“私聊”后选择对象，或点击“新私聊”输入准确的角色名。平板横竖屏及手机横屏时，对象列表位于分类右侧；仅手机竖屏将对象列表放在消息内容下方。长名称在列表中省略，选中后的消息区顶部显示完整名字。

![罗安的平板私聊入口](/images/game/social/tablet-chat.png)

新建对象只是选择收件人，不证明角色存在或在线；发送结果以聊天提示为准。删除对象选项不会删除游戏好友关系。私聊并非排他会话，第三个人仍能分别向双方发送消息。

消息流保存在当前页面内存中，不作为长期历史记录；重新加载页面或退出后不要依赖它恢复聊天记录。

选择表情并发送成功后，聊天窗口立即关闭，方便查看角色表情；发送失败时保留窗口和提示。发送普通文字不会关闭聊天窗口。

## 好友、队伍与公会

选中列表中的成员后查看详情，再使用底栏操作。好友请求需要对方接受；成员在线、等级与地图等显示以服务器返回的信息为准。

![选中好友后查看在线状态、等级与中文地图名](/images/game/social/tablet-social-friend.png)

队伍列表包含自己是正常的；选中自己可以查看资料，成员管理操作受身份与权限限制。公会管理同样由服务器检查，不能因为选中了成员就假定可以移除或修改其身份。

移动端点击其他玩家可以发起私聊、查看对方允许公开的装备、添加好友或交易；交易步骤见[交易与摆摊](/game/trading)。

## 添加与删除好友

1. 手机和平板点击对方玩家，选择「好友」；也可以打开「社交 → 好友 → 好友管理」，填写准确角色名并点击「添加好友」。
2. 对方在请求窗口选择确定后，双方好友列表出现彼此。
3. 选中好友可查看在线状态并发起私聊；删除好友需再次确认。

好友请求与交易请求是不同操作。对方拒绝、离线或名字不正确时，按实际提示处理，不要把输入框中的名字当作已添加成功。

## 创建与管理队伍

在「社交 → 队伍 → 队伍管理」输入队伍名并创建，确认后才建立队伍。队长可填写角色名邀请入队，对方接受后进入成员列表。

![玛雅邀请罗安入队后查看成员和分配设置](/images/game/social/tablet-social-party.png)

队长可以调整队伍分配选项、转交队长或移出成员；普通成员可以退出队伍。选中成员后先核对角色名，再执行管理操作。经验共享还受成员等级等服务器规则限制，界面允许选择不代表任何组合都能共享经验。

## 公会与氏族

「社交 → 公会」用于查看公会资料、成员及公告。尚未加入时可按入口申请创建，所需材料和资格由服务器检查；邀请、职位、公告、退出与解散操作按当前身份开放。

公会会长执行管理前应先刷新资料并确认目标成员。退出和解散是实际组织变更，不是关闭窗口。氏族属于独立系统，通过对应 NPC 加入，聊天中的氏族频道只对已加入成员有意义。

## 手机输入与聊天预览

手机和平板点击文本框时，可能打开独立输入窗口；填写后点「完成」返回原面板，再执行发送或提交。输入完成不等于已经发送。

聊天预览可以收起；完整频道和私聊对象在聊天菜单中管理。预览行数、分类标签见[画面、声音与镜头](/game/settings)。

## 桌面聊天室

电脑按 Alt + C 打开「创建房间」，填写标题、人数上限，选择公开或私人；私人房间还需设置密码，核对后确认创建。它是在场景中建立的独立聊天室，不等于附近频道或私聊。

![桌面聊天室的标题、人数和公开设置](/images/game/social/desktop-chat-room.png)

其他玩家通过房间牌子进入，私人房间需要密码；房主可管理房间，离开时按房间内操作退出。当前触屏主菜单没有对应的完整房间管理入口，手机和平板交流优先使用聊天频道与私聊。
