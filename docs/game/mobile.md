# 手机平板

::: tip Safari 登录问题（待修复）
移动端的 Safari 使用 HTTP 访问时存在 WebSocket 连接问题，可能会导致无法登录。请改用 HTTPS，或暂用 Chrome 访问。
:::

HappyRO 为触屏设备提供独立的游戏界面，适用于 iPhone、iPad 和 Android 手机、平板。左手控制移动，右手使用技能与道具，常用菜单和战斗设置都可以直接点按。

## 登录与进入游戏

打开 HappyRO 启动页，点击「进入游戏」即可登录。也可以通过浏览器的安装或添加到主屏幕入口，以 PWA 方式从桌面打开。

![手机平板横屏登录界面](/images/game/mobile/happyro-mobile-login.jpg)

登录界面支持横屏和竖屏；进入游戏场景时需要横屏。出现旋转提示时，请将设备转为横屏，并确认系统没有锁定竖屏方向。

## 创建与选择角色

创建角色时，左侧选择种族，中间填写名称、选择性别并预览人物，右侧选择发型。人物两侧的箭头用于调整预览朝向，确认后点击底部「生成」。

![手机平板横屏创建角色界面](/images/game/mobile/happyro-mobile-char-create.jpg)

横屏选角界面左侧以两列展示角色，右侧查看所选角色的属性，再进入游戏。

![手机平板横屏选择角色界面](/images/game/mobile/happyro-mobile-char-select.jpg)

## 游戏界面与触屏操作

![手机平板在普隆德拉南门的游戏画面](/images/game/mobile/happyro-mobile-southgate.jpg)

左上角显示角色信息和 HP、SP，下方是「菜单」和「状态」入口；右上角显示小地图、地图名称与坐标。右下角集中放置战斗状态、自动战斗、快捷栏翻页与槽位配置，每页显示 6 个快捷槽位。

| 操作 | 使用方式 |
| --- | --- |
| 移动 | 在画面左侧的场景区域按住并拖动手指，角色随方向移动；松手停止，不显示摇杆 |
| 与 NPC 交谈 | 直接点击 NPC，角色会靠近并交谈，无需再点交谈按钮 |
| 拾取物品 | 直接点击地上的物品，角色会靠近并拾取 |
| 攻击一只魔物 | 点击魔物，角色会接近并攻击该目标；未开启自动战斗时，不会在击败后继续寻找其他魔物 |
| 使用道具 | 点击已配置的道具槽位 |
| 使用指向性技能 | 先点击技能槽位，再点击目标魔物；距离不足时会先靠近目标 |
| 取消技能选择 | 点击快捷栏上方的「取消施法」 |

移动与技能点按可以配合使用，无需先松开移动手指再选择技能。自动战斗开启时，点击魔物可以临时指定当前攻击目标，之后继续按配置寻找目标。

## 配置快捷槽位

点击右下角「配置槽位」打开快捷配置。先通过快捷栏的翻页按钮选择要配置的一页。

![手机平板快捷槽位配置界面](/images/game/mobile/happyro-mobile-quick-slots.jpg)

1. 在顶部选择要修改的槽位。
2. 从列表选择已学技能或背包中的可用道具。
3. 选择技能时，可调整释放等级，再保存到当前槽位。
4. 不再需要的内容可以通过「清空当前槽位」移除。

快捷槽位决定手动点击时使用的技能或道具；自动战斗的技能在独立的战斗设置中选择。

## 自动战斗

点击右下角的魔物目标选择入口打开「自动战斗设置」。配置完成后点击「保存配置」，面板会关闭，再点击「自动战斗」开始。

![手机平板自动战斗设置界面](/images/game/mobile/happyro-mobile-auto-fight.jpg)

### 选择魔物与攻击方式

攻击目标支持多选魔物种类；选择「全部魔物」或不勾选种类时，会攻击范围内的全部魔物。击败目标后会继续寻找符合配置的下一只魔物。

默认使用普通攻击。勾选多个技能后，会从当前可用的技能中随机选择，使用已学最高等级；技能均不可用时使用普通攻击。

### 调整战斗范围

展开魔物选择下方的「范围设置」，按地图格数配置：

| 配置 | 含义 | 默认值 | 可设置范围 |
| --- | --- | --- | --- |
| 搜索半径 | 从角色当前位置寻找目标的距离 | 20 格 | 1–50 格 |
| 活动半径 | 限制追击目标离本次活动起点的距离 | 30 格 | 1–100 格，且不小于搜索半径 |

范围增大后可以寻找更远的目标，但仍受客户端已知魔物和地图可通行区域限制，不会自动在全地图巡逻。附近没有目标时，可以手动移动到其他区域继续寻找。

### 移动、停止与保存

自动战斗期间手动移动，会暂时暂停攻击；停止移动后会继续自动战斗，并以移动后的位置作为新的活动起点。点击「停止战斗」则结束自动战斗，需要手动再次开启。

「保存配置」会保存魔物种类、攻击技能和范围设置。下次使用同一设备、同一浏览器登录同一角色时会恢复配置，但不会自动开始战斗。配置按角色保存在本地，换设备、换浏览器或清除站点数据后需要重新设置。

## 添加到桌面（PWA）

打开 HappyRO 的 **HTTPS 游戏启动页**，按以下步骤添加：

- **iPhone／iPad（Safari、Chrome）**：分享 → 添加到主屏幕 → 添加；如有「作为网页 App 打开」，请开启。
- **Android（Chrome）**：右上角菜单 → 安装应用／添加到主屏幕 → 安装。

之后从桌面 HappyRO 图标打开，即可隐藏浏览器工具栏，横屏游玩；系统手势条可能保留。

### 当前限制与待完善项

- 地图导航目前提供目的地搜索和路线预览，自动行走与停止操作尚未完成。
- 生命体／佣兵的直接指定攻击、移动目的地及完整技能详情仍待补齐。
- 聊天室未完成独立移动适配；商城与奖励、验证码、部分装备／技能附加窗口、通知与表情等尚未完成全面核对。
- 部分设置入口、返回选角流程，以及游戏工具中的其他业务仍待补充验收。

以上表示已接入的功能范围，不代表所有设备与业务流程均已验收完成。iPhone 实机、多指与软键盘、后台恢复、换图与断线，以及真实交易、材料消耗等场景仍需继续确认。
