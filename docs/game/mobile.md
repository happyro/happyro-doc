# 手机平板

::: tip Safari 登录问题（待修复）
移动端的 Safari 使用 HTTP 访问时存在 WebSocket 连接问题，可能会导致无法登录。请改用 HTTPS，或暂用 Chrome 访问。
:::

HappyRO 为触屏设备提供独立的游戏界面，适用于 iPhone、iPad 和 Android 手机、平板。左手控制移动，右手使用技能与道具，常用菜单和战斗设置都可以直接点按。

本文按当前开发版本（v0.4.0，未发布）说明；已发布 v0.3.2 不包含全部功能。截图展示部分横屏界面，实际布局会随可用空间调整。

## 登录与进入游戏

打开 HappyRO 启动页，点击「进入游戏」即可登录。也可以通过浏览器的安装或添加到主屏幕入口，以 PWA 方式从桌面打开。

![手机平板横屏登录界面](/images/game/mobile/happyro-mobile-login.jpg)

登录和游戏场景均支持横竖屏切换，不再强制横屏。手机竖屏默认拉远镜头三步，切回横屏恢复基础距离；平板和分屏按实际可用空间调整布局。

勾选「保持登录」后，同一入口、同一浏览器最多 30 天免密登录，重新打开页面进入选角。HTTP 和 HTTPS 均支持，但两种入口需分别首次登录。未勾选时只在当前页面保持会话，刷新或关闭后需重新登录。

页面内意外断线会尝试恢复原角色，同地图恢复镜头；位置与角色状态以服务端为准，不恢复交易或 NPC 对话，也不重放技能、购买等操作。主动退出登录、凭据过期、修改密码或封禁后需重新认证。手机系统回收页面等同重新打开，不能保证回到原画面；后台冻结与恢复仍需真机验收。

## 创建与选择角色

创建角色时，左侧选择种族，中间填写名称、选择性别并预览人物，右侧选择发型。人物两侧的箭头用于调整预览朝向，确认后点击底部「生成」。

![手机平板横屏创建角色界面](/images/game/mobile/happyro-mobile-char-create.jpg)

横屏选角界面左侧以两列展示角色，右侧查看所选角色的属性，再进入游戏。

![手机平板横屏选择角色界面](/images/game/mobile/happyro-mobile-char-select.jpg)

## 游戏界面与触屏操作

![手机平板在普隆德拉南门的游戏画面](/images/game/mobile/happyro-mobile-southgate.jpg)

左上角显示角色信息和 HP、SP，下方提供「菜单」「状态」「聊天」「镜头」入口；右上角显示小地图、地图名称与坐标。右下角集中放置战斗状态、自动战斗、快捷栏翻页与槽位配置，每页显示 6 个快捷槽位。

| 操作 | 使用方式 |
| --- | --- |
| 移动 | 在画面左侧的场景区域按住并拖动手指，角色随方向移动；松手停止，不显示摇杆 |
| 与 NPC 交谈 | 直接点击 NPC，角色会靠近并交谈，无需再点交谈按钮 |
| 拾取物品 | 直接点击地上的物品，角色会靠近并拾取 |
| 攻击一只魔物 | 点击魔物，角色会接近并攻击该目标；未开启自动战斗时，不会在击败后继续寻找其他魔物 |
| 使用道具 | 点击已配置的道具槽位 |
| 使用指向性技能 | 先点击技能槽位，再点击目标魔物；距离不足时会先靠近目标 |
| 取消技能选择 | 点击快捷栏上方的「取消施法」 |

移动与技能点按可以配合使用，无需先松开移动手指再选择技能。自动战斗开启时，点击魔物可以临时指定当前攻击目标，之后继续按配置寻找目标。

## 配置快捷槽位

点击右下角「配置槽位」打开快捷配置。先通过快捷栏的翻页按钮选择要配置的一页。

![手机平板快捷槽位配置界面](/images/game/mobile/happyro-mobile-quick-slots.jpg)

1. 在顶部选择要修改的槽位。
2. 从列表选择已学技能或背包中的可用道具。
3. 选择技能时，可调整释放等级，再保存到当前槽位。
4. 不再需要的内容可以通过「清空当前槽位」移除。

快捷槽位决定手动点击时使用的技能或道具；自动战斗的技能在独立的战斗设置中选择。

## 自动战斗

点击右下角的魔物目标选择入口打开「自动战斗设置」。配置会自动保存，关闭面板后点击「自动战斗」开始。

![手机平板自动战斗设置界面](/images/game/mobile/happyro-mobile-auto-fight.jpg)

### 选择魔物与攻击方式

攻击目标支持多选魔物种类；选择「全部魔物」或不勾选种类时，会攻击范围内的全部魔物。击败目标后会继续寻找符合配置的下一只魔物。

默认使用普通攻击。勾选多个技能后，会从当前可用的技能中随机选择，使用已学最高等级；技能均不可用时使用普通攻击。

### 调整战斗范围

展开魔物选择下方的「范围设置」，按地图格数配置：

| 配置 | 含义 | 默认值 | 可设置范围 |
| --- | --- | --- | --- |
| 搜索半径 | 从角色当前位置寻找目标的距离 | 20 格 | 1–50 格 |
| 活动半径 | 限制追击目标离本次活动起点的距离 | 30 格 | 1–100 格，且不小于搜索半径 |

范围增大后可以寻找更远的目标，但仍受客户端已知魔物和地图可通行区域限制，不会自动在全地图巡逻。附近没有目标时，可以手动移动到其他区域继续寻找。

### 移动、停止与保存

自动战斗期间手动移动，会暂时暂停攻击；停止移动后会继续自动战斗，并以移动后的位置作为新的活动起点。点击「停止战斗」则结束自动战斗，需要手动再次开启。

魔物种类、攻击技能和范围设置会自动保存，关闭面板时也会保存尚未写入的数值。下次使用同一设备、同一浏览器登录同一角色时会恢复配置，但不会自动开始战斗。配置按角色保存在本地，换设备、换浏览器或清除站点数据后需要重新设置。

## 添加到桌面（PWA）

打开 HappyRO 的 **HTTPS 游戏启动页**，按以下步骤添加：

- **iPhone／iPad（Safari、Chrome）**：分享 → 添加到主屏幕 → 添加；如有「作为网页 App 打开」，请开启。
- **Android（Chrome）**：右上角菜单 → 安装应用／添加到主屏幕 → 安装。

之后从桌面 HappyRO 图标打开，即可隐藏浏览器工具栏，横屏或竖屏游玩；系统手势条可能保留。

## 移动端适配范围

本次适配除了上述主界面，也覆盖了常用游戏窗口的触屏布局和操作。以下按功能汇总当前实现范围；功能是否可用，还取决于角色职业、权限及服务器开放情况。

| 功能范围 | 已接入的移动端界面与交互 |
| --- | --- |
| 登录与角色 | 登录、注册入口、选角、创建角色，横竖屏布局与人物预览 |
| 游戏主界面与 PWA | 状态栏、菜单、聊天与镜头入口、小地图、游戏内横竖屏切换、系统安全区适配、启动与过图加载图、触屏隐藏鼠标指针 |
| 移动与战斗 | 左侧拖动移动、多指操作、直接交谈和拾取、点击魔物攻击、追近施法、六槽分页、自动战斗与配置保存 |
| 背包与装备 | 分类、详情、使用、排序、数量选择与丢弃确认，装备穿脱、更换及属性查看；骑乘期间可在装备底栏解除坐骑或卸下机甲 |
| 素质与技能 | 基础／四转素质加点与重置，技能目录、说明、前置条件、学习与升级确认、释放等级、快捷绑定及技能点重置 |
| 冒险工具 | 地图、魔物、NPC、物品图鉴与权限允许的角色／游戏设置；当前地图寻路与停止、允许的传送操作 |
| NPC 与商店 | 对话、菜单、文字及数字输入，普通、点数、限量与兑换商店的数量选择、订单核对与确认 |
| 仓库与手推车 | 分类查看、数量选择、背包／仓库／手推车之间转移；手推车菜单支持确认卸下，重新使用时可向 NPC 租用或在冒险工具中租用，车内物品保留 |
| 任务与地图 | 任务分类、目标进度、奖励与启停，当前地图、世界区域、名称与地图 ID 搜索 |
| 社交 | 好友、队伍、公会的信息与管理面板，公会技能、职位与徽章操作；聊天入口、消息面板与表情列表，未学习所需技能时显示明确提示 |
| 特殊技能与物品 | 传送、鉴定、技能选择、制作与材料选择、修理、手推车外观及怪物识别等窗口 |
| 装备强化 | 卡片镶嵌、精炼、评级、附魔、合成、升级、改造与装备方案切换 |
| 交易与摊位 | 玩家交易、售卖与收购摊位，数量、金额和确认操作 |
| 银行与邮件 | 银行存取；邮件分类、搜索、阅读、附件、写信与删除确认 |
| 宠物与伴侣 | 宠物状态、基础操作、捕捉、蛋选择与进化；生命体／佣兵状态、基础指令、技能学习与快捷施法 |
| 游戏设置 | 画面、声音与镜头设置，保存、取消和恢复默认 |

冒险工具的游戏设置支持精炼成功率倍率与「精炼必定成功」，与桌面端及后台共用配置和权限。默认 1 倍、必定成功关闭；开启后保留并禁用倍率输入，材料、装备限制及评级规则保持不变。

### 当前限制与待完善项

- 冒险工具自动寻路仅支持角色当前地图；跨地图路线预览不等于自动完成跨图交互。自动战斗不支持全地图巡逻。
- 生命体／佣兵的直接指定攻击、移动目的地及完整技能详情仍待补齐。
- 聊天室未完成独立移动适配；商城与奖励、验证码、部分装备／技能附加窗口、通知等尚未完成全面核对。
- 部分设置与游戏工具操作，以及真实消耗场景仍待补充验收；模拟视口通过不代表全部真机流程通过。

以上表示已接入的功能范围，不代表所有设备与业务流程均已验收完成。iPhone 实机、多指与软键盘、后台恢复、换图与断线，以及真实交易、材料消耗等场景仍需继续确认。

### 骑乘与随行

在「冒险工具 → 角色 → 骑乘与随行」中，可按当前职业租用／卸下手推车、骑乘／下骑大嘴鸟及龙和狮鹫、驾驶／解除驾驶魔导机甲，桌面、手机和平板共用。需要先学习相应技能，使用前会显示并确认费用；租金采用普隆德拉对应 NPC 的规则。机匠的机甲与手推车分别操作，卸下手推车不会清空车内物品。此功能沿用冒险工具的角色维护权限。
