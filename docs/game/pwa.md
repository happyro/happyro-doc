# 添加到主屏幕（PWA）

## 添加到桌面（PWA）

打开 HappyRO 的 **HTTPS 游戏启动页**，按以下步骤添加：

- **iPhone／iPad（Safari、Chrome）**：分享 → 添加到主屏幕 → 添加；如有「作为网页 App 打开」，请开启。
- **Android（Chrome）**：右上角菜单 → 安装应用／添加到主屏幕 → 安装。

之后从桌面 HappyRO 图标打开，即可隐藏浏览器工具栏，横屏或竖屏游玩；系统手势条可能保留。

## 登录与后台恢复

添加到主屏幕不代表浏览器会一直在后台运行。保持登录、页面回收和断线恢复的区别见[登录与角色](/game/getting-started)。自动战斗不会因重新登录自动恢复，见[自动战斗与拾取](/game/combat)。

访问部署机器的局域网地址前，先确认设备能打开同一启动页；需要 HTTPS 域名时见[反向代理](/deploy/reverse-proxy)。
