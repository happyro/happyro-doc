# NPC 对话附魔

核对日期：2026-10-29。本页列出使用 NPC 对话处理的附魔装备，统计口径与验证范围见[附魔与升阶总览](/game/equipment-services#数量汇总)，窗口操作方式见[专用窗口附魔](/game/window-enchantment)。

从当前加载的 NPC 服务中核对到 **1,160 件不同目标装备**：其中 **1,021 件**具备可加载的图标与详情图、有效说明，并由普通权限角色实际穿戴成功；98 件缺少完整图片／资料，41 件说明仍为占位文本，未计入核验清单。同一装备可能出现在多个服务中，分组数量不能直接相加。

本页的“穿戴验证职业”只是实际验证过的一种职业，不是唯一可用职业；要求等级是装备自身的最低等级，还需要满足职业、性别和转职条件。服务入口、目标范围按当前正式加载的 NPC 脚本核对，未逐一消耗材料执行所有 NPC 的附魔分支。

## 使用方法

先用浏览器页面搜索查找装备 ID，再查看所属服务的地图与坐标。手机和平板也可以通过游戏图鉴按 ID 查询名称与说明。展开对应清单即可查看全部通过资料与穿戴核验的装备。

旧式附魔按各 NPC 的规则执行：可能要求先穿上装备、完成任务、达到精炼等级，或准备特定币种。**不能套用专用附魔窗口的材料、成功率和重置规则。** 部分服务会重建装备、清除精炼或卡片，失败也可能损毁；确认前阅读 NPC 当次说明。

本清单覆盖对玩家持有装备追加、强化或重置附魔的服务。仅发放带固定／随机属性的任务奖励、拆卡、打孔、装备改造和随机词条制造不作为同一种附魔服务统计。
