# 画面、声音与镜头

手机和平板打开「菜单 → 设置」，按「画面」「特效」「声音」切换。电脑从选项进入对应设置；镜头也可直接用鼠标操作。这里的设置影响当前浏览器的游玩体验，全服倍率等规则在[冒险工具](/game/adventure-tools#角色与游戏设置)中单独管理。

## 调整画面

![平板画面设置，包括渲染比例、帧率及聊天预览](/images/game/settings/tablet-settings.png)

1. 打开「画面」，根据设备性能调整渲染比例、帧率及可视范围。
2. 觉得画面卡顿时，可先降低渲染比例或特效数量，再观察实际效果。
3. 按需要设置聊天预览行数、分类标签和通知显示时长。聊天内容仍可从完整聊天窗口阅读。

设置修改会即时保存，不需要寻找「应用」按钮。手机和平板的聊天行数按当前布局设置；切换设备或清除站点数据后，应重新检查本地偏好。

## 特效与声音

![平板特效设置](/images/game/settings/tablet-settings-effects.png)

「特效」调整画面效果，关闭效果不会取消技能或服务器判定。不要仅凭某个特效是否可见判断技能成功。

![背景音乐和音效各自设置开关及音量](/images/game/settings/tablet-settings-audio.png)

「声音」分别控制背景音乐、音效和各自音量。开启后没有声音时，先检查设备静音、浏览器站点声音权限，并在游戏页面点击一次。

「恢复默认」会要求确认，并恢复画面、特效和声音设置；它不用于重置角色技能、物品或战斗辅助配置。

## 镜头

手机和平板点击左上角「镜头」，用「左转／右转」「拉近／拉远」「抬高／降低」调整视角。「重置镜头」恢复默认视角。

![平板镜头控制](/images/game/settings/tablet-camera.png)

电脑可通过鼠标调整镜头，具体手势见[界面与操作](/game/controls)。手机横竖屏切换会影响可见范围；先调整到能看清角色和目标的位置，再进行战斗或 NPC 操作。

## 返回选角与退出

手机和平板使用「菜单 → 返回选角」，确认后回到角色列表；电脑使用退出选项中的对应操作。先完成或取消交易、摆摊、仓库与 NPC 对话，再离开角色。

保持登录、断线恢复以及安装到主屏幕分别见[登录与角色](/game/getting-started)和 [PWA](/game/pwa)。
