# 交易与摆摊

玩家间交易需要双方确认，摆摊需要相应职业技能和可售物品。请先确认角色的职业、技能、手推车与物品条件。

## 玩家交易

手机和平板点击对方角色后选择“交易”，确认对方姓名并发出请求，等待对方接受。平板横竖屏与手机横屏采用三列布局：可交易物品、我方、对方。双方金额显示在各自标题右侧。

![罗安的平板交易界面，双方物品与金额分栏展示](/images/game/trading/tablet-trade.png)

1. 用分类、子类和搜索筛选物品，选择物品并填写数量，加入交易。不可交易或对方容量不足时会提示原因。
2. 点击底部“设置金额”，在弹窗中填写 Zeny；未设置时输入框为空，留空确认按 0 处理。确认后核对我方标题右侧的金额。
3. 核对双方物品与金额，再点击“锁定交易”。
4. 双方锁定后点击“确认成交”，在两列核对窗口中再次确认，等待服务器结果。

![确认成交前核对双方物品及金额](/images/game/trading/tablet-trade-confirm.png)

手机竖屏从上到下为对方、我方、可交易物品；筛选位于物品列表下方，设置金额、锁定和成交操作统一位于底栏。

锁定与成交是两个阶段。等待服务器响应时不要重复提交；关闭、拒绝或取消以服务器结果为准。电脑同样需要报价锁定及确认，按钮状态会反映当前阶段。

## 摆摊

使用摆摊技能前准备手推车、可售物品及技能要求。移动端摆摊界面按可选商品与摊位清单组织，可使用分类、子类筛选。

1. 学习「露天商店」，租用手推车，并把准备出售的商品放进车内。
2. 通过技能窗口或已绑定的快捷栏施放「露天商店」，打开摆摊清单。
3. 选中商品后通过箭头加入清单，填写数量和单价；移除商品使用反向箭头。
4. 核对清单后点击「确认」，在「摊位名称」输入窗口填写名称并提交，等待服务器开店结果。

商品种类数量受所用技能等级限制，单价按每件物品填写。玛雅是本指南的商人系演示角色；剑士罗安不能仅靠打开相同菜单获得摆摊能力。

自己的摊位也有牌子，可从相关入口查看摊位状态；开店后以服务器库存和售卖结果为准。买家购买界面、玩家交易和摆摊是不同流程，不要把“加入清单”当成交易已经完成。

## 条件与限制

角色距离、交易资格、可交易物品、负重、金额及摊位条件由服务器判断。界面提示失败时先核对原因；不要用再次点击确认代替核对结果。[邮件与附件](/game/mail)、银行和仓库不属于玩家交易流程。

![玛雅配置售卖商品、数量和单价](/images/game/trading/tablet-vending-setup.png)

## 向玩家摊位购买

双击摊位牌子打开商品列表；手机和平板可连续点按牌子，或选择摊主后使用出现的摊位操作入口。选择商品、填写数量并核对单价及总额，确认后等待购买结果，再检查背包和 Zeny。库存来自卖家的实际摊位，其他买家可能先买走商品。

NPC 商店、玩家摊位和玩家直接交易使用不同流程；向摊位购买无需卖家逐次点击交易确认。

![罗安向玛雅的摊位购买红色药水，确认前查看合计](/images/game/trading/tablet-vending-buy.png)

## 查看与关闭自己的摊位

开店后从「菜单 → 我的摊位」查看当前商品及销售情况。尚未开店时，该入口只会提示先使用摆摊或收购技能。

点击「关闭摊位」并确认才是收摊；关闭查看窗口与关闭摊位不同。需要调整商品或价格时，先收摊，再重新准备清单。

![玛雅查看自己已经开张的摊位](/images/game/trading/tablet-vending-owned.png)

## 收购摊位

具备收购技能或对应道具时，通过其实际入口打开收购清单，选择允许收购的物品，填写数量、单价及收购预算，再核对并开店。普通出售摊位从手推车卖出商品，收购摊位则用预算购买别人的物品，不能把两个清单混为一谈。

对方收购摊位只接收其指定且符合规则的物品。没有收购能力时，「我的摊位」不会替你解锁；材料、预算及可收购物品由服务器检查。
