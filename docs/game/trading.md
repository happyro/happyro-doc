# 交易与摆摊

::: info 适用版本
本页按当前主分支说明，包含 v0.5.0 开发中功能；已发布离线包以[下载页](/guide/downloads)与对应版本说明为准。
:::

玩家间交易需要双方确认，摆摊需要相应职业技能和可售物品。请先确认角色的职业、技能、手推车与物品条件。

## 玩家交易

手机和平板点击对方角色后选择“交易”，等待对方接受。交易窗口左侧选择可交易物品，右侧核对双方报价。

1. 选择物品并填写数量，加入交易。
2. 输入 Zeny 时点击“设置金额”，确认金额已经进入报价；不使用时撤销未提交的修改。
3. 核对双方物品与金额，再点击“锁定报价”。
4. 双方达到可确认状态后点击“确认成交”，等待服务器结果。

锁定与成交是两个阶段。等待服务器响应时不要重复提交；关闭、拒绝或取消以服务器结果为准。电脑同样需要报价锁定及确认，按钮状态会反映当前阶段。

## 摆摊

使用摆摊技能前准备手推车、可售物品及技能要求。移动端摆摊界面按可选商品与摊位清单组织，可使用分类、子类筛选。

选中商品后通过箭头加入清单，填写数量和单价；移除商品使用反向箭头。核对清单后点击“确认”，在“摊位名称”输入窗口填写名称并提交，等待服务器开店结果。

自己的摊位也有牌子，可从相关入口查看摊位状态；开店后以服务器库存和售卖结果为准。买家购买界面、玩家交易和摆摊是不同流程，不要把“加入清单”当成交易已经完成。

## 条件与限制

角色距离、交易资格、可交易物品、负重、金额及摊位条件由服务器判断。界面提示失败时先核对原因；不要用再次点击确认代替核对结果。邮件、银行和仓库不属于玩家交易流程。
