# 登录与角色

## 登录与进入游戏

打开 HappyRO 启动页，点击「进入游戏」即可登录。也可以通过浏览器的安装或添加到主屏幕入口，以 PWA 方式从桌面打开。

登录和游戏场景均支持横竖屏切换。手机竖屏会调整镜头距离；平板和分屏按实际可用空间调整布局。

勾选「保持登录」后，同一入口、同一浏览器最多 30 天免密登录，重新打开页面进入选角。HTTP 和 HTTPS 均支持，但两种入口需分别首次登录。未勾选时只在当前页面保持会话，刷新或关闭后需重新登录。

页面内意外断线会尝试恢复原角色，同地图恢复镜头；位置与角色状态以服务端为准，不恢复交易或 NPC 对话，也不重放技能、购买等操作。主动退出登录、凭据过期、修改密码或封禁后需重新认证。手机系统回收页面等同重新打开，不能保证回到原画面；后台冻结与恢复仍需真机验收。

## 注册账号

点击登录窗口的「注册」查看当前服务器提供的入口。配置了注册网站时，会引导到相应页面；未配置时，窗口说明自动注册方式。

服务器允许自动注册时，首次在账号名末尾添加 `_M` 或 `_F`，输入要设置的密码后登录。例如首次输入 `adventurer_M`，后续使用 `adventurer` 登录。账号已存在时不能用这个方法重置密码；账号创建是否开放以当前服务器设置为准。

账号名与角色名不同：登录使用账号名，好友、私聊和邮件使用角色名。默认测试账号见[安装文档](/deploy/docker#默认账号)。

## 创建与选择角色

创建角色时，左侧选择种族，中间填写名称、选择性别并预览人物，右侧选择发型。人物两侧的箭头用于调整预览朝向，确认后点击底部「生成」。

横屏选角界面左侧以两列展示角色，右侧查看所选角色的属性，再进入游戏。

手机竖屏把角色列表放在上方，所选角色的属性和进入按钮放在下方。

## 出生与新手任务

人类角色按服务器设置进入经典修炼场或沉船学院；杜兰角色从拉萨格纳开始独立的出生任务。跟随当前 NPC 对话与任务说明推进，领取奖励前为实际奖励预留负重和物品栏位；背包满时先整理，再回原 NPC 继续。

桌面端可用 Alt+U 查看任务、Alt+E 打开背包、Alt+S 查看技能；手机和平板通过菜单打开对应窗口。任务中的 NPC 名称和导航与场景显示保持一致，剧情中的化名或身份揭示前的称呼仍可能不同。

学院的忍者基础指导由科·奥利直接讲解技能点、施放条件和快捷栏，听完后完成任务。宠物教学需要先完成其前置指引，不能跳过对话直接领取最终奖励。
