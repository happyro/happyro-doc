# 宠物、生命体与佣兵

## 孵化与查看宠物

背包持有宠物蛋和携带用孵蛋器时，使用孵蛋器，选择宠物蛋并在底栏确认。选中蛋只是在查看候选，确认后才向服务器请求孵化。

![选择波利宠物蛋并核对孵化操作](/images/game/companions/tablet-pet-hatch.png)

孵化后从「菜单 → 宠物」查看名称、等级、饥饿和亲密等状态，也可以直接点击场景中的宠物。宠物需要适合它的食物；没有食物或条件不满足时按提示处理。

![罗安的波利宠物状态和操作入口](/images/game/companions/tablet-pet.png)

## 选择与快捷操作

手机／平板点击自己的随行单位后显示对应快捷操作：

| 单位 | 快捷操作 |
| --- | --- |
| 宠物 | 查看、喂食、表演、收回 |
| 生命体 | 查看、喂食、返回、主动／被动 |
| 佣兵 | 查看、返回、主动／被动、解除 |

喂食、收回或解除等需要确认的操作会绑定当前单位；单位消失、切图或主人死亡后，旧确认不能操作新单位。详细状态与技能仍从对应菜单查看。右下角左侧「取消」清除当前随行单位选择，右侧自动战斗按钮仍独立启停。

宠物和生命体允许重复改名，名称按 UTF-8 字节长度校验；等待服务器结果时不能重复提交。自动喂食是否支持及开启状态以服务器为准。

宠物进化按当前服务器配方显示目标与条件，多分支分别选择。确认前需满足亲密、饰品和材料条件；孵化、收回或更换宠物后重新打开进化入口。

## 生命体与佣兵入口

生命体需要对应职业技能和召唤条件，佣兵需要相应契约或服务；剑士拥有宠物不代表可以直接召出生命体。获得单位后，从「菜单 → 生命体／佣兵」查看状态、技能和当前可用操作。

技能列表用于查看技能说明与已学等级；执行指令仍受单位状态和服务器条件限制。佣兵解除与暂时让单位返回身边不同，确认前检查按钮说明。没有已召唤单位时，面板显示提示，不会自动召唤。

## 主动与被动

生命体和佣兵的按钮文字表示当前模式，点击切换到另一模式；「主动」「被动」均使用黄色，不用颜色表示开关。按钮与其他随行动作独立放在战斗信息框外，显示期间隐藏战斗信息。

主动模式允许 AI 寻找附近可见魔物；被动模式不主动获取无关魔物，但仍能参与角色或随行单位已经开始的战斗，包括受到攻击或明确指定的目标。被动不等于完全停止攻击。模式按本机浏览器保存，生命体和佣兵分别设置。

该模式独立于角色的自动战斗开关；停止角色自动战斗不等于把随行单位切为被动，反之也不会自动开启角色战斗。随行单位仍受自身 AI、距离、状态和服务器规则约束。

## 使用边界

本文介绍随行单位的面板与快捷操作；各职业技能的效果、消耗、召唤和地图限制由服务器判定。手机和平板使用已列出的快捷操作，不把主动／被动切换当成直接指定移动坐标或施放任意技能。

职业自带的骑乘、猎鹰、战狼与鹰见[职业外观与骑乘](/game/appearance)。
