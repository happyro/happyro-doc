# 职业外观与随行

本文说明 v0.5.0 开发中功能，尚未发布。各项操作按角色职业、技能及权限开放；不可用时以界面和服务端提示为准。

## 选择职业外观

打开「冒险工具 → 角色 → 职业外观」，从当前职业允许的旧阶段外观中选择，选择「默认外观」恢复真实职业显示。当前覆盖十二条主职业线，诗人／舞娘分开，共十三分支、39 个旧阶段选项；不能跨职业线任意换装。

外观只改变显示，真实职业、属性、技能和装备资格保持不变。选择按角色保存，同步到附近玩家及选角页；转职或性别变化后会重新检查是否仍适用。

人物服装和对应坐骑作为一个外观选项，不能分别搭配。例如骑士外观在骑乘时显示骑士与大嘴鸟组合。若所选外观没有当前骑狼或机甲形态，会暂时显示真实职业的完整形态，解除后恢复所选外观；保存的选择不会丢失。

死亡、NPC 对话、交易、仓库或摆摊期间可能无法修改，请先结束相关操作。外观资源加载失败时本地恢复默认显示，不改变服务器保存值。

## 骑乘与随行

在「冒险工具 → 角色 → 骑乘与随行」中，可按当前职业租用／卸下手推车、骑乘／下骑大嘴鸟及龙和狮鹫、驾驶／解除驾驶魔导机甲，桌面、手机和平板共用。需要先学习相应技能，使用前会显示并确认费用；租金采用普隆德拉对应 NPC 的规则。机匠的机甲与手推车分别操作，卸下手推车不会清空车内物品。此功能沿用冒险工具的角色维护权限。

十字军／圣殿十字军可骑乘大嘴鸟，皇家禁卫军／帝国禁卫军可骑乘狮鹫。猎人分支可租用／解除猎鹰；游侠及风鹰可召唤／召回战狼、骑乘／下骑战狼，下骑后恢复随行；风鹰还可召唤／召回鹰。战狼和鹰通过原技能施放，需学习对应技能，并满足 SP、狼笛／猎鹰笛等道具及动作间隔要求；猎鹰与战狼的互斥及风鹰共存规则沿用服务端技能规则。

## 宠物、生命体与佣兵

手机／平板点击自己的随行单位后显示对应快捷操作：

| 单位 | 快捷操作 |
| --- | --- |
| 宠物 | 查看、喂食、表演、收回 |
| 生命体 | 查看、喂食、返回、主动／被动 |
| 佣兵 | 查看、返回、主动／被动、解除 |

喂食、收回或解除等需要确认的操作会绑定当前单位；单位消失、切图或主人死亡后，旧确认不能操作新单位。详细状态与技能仍从对应菜单查看。

宠物和生命体允许重复改名，名称按 UTF-8 字节长度校验；等待服务器结果时不能重复提交。自动喂食是否支持及开启状态以服务器为准。

宠物进化按当前服务器配方显示目标与条件，多分支分别选择。确认前需满足亲密、饰品和材料条件；孵化、收回或更换宠物后重新打开进化入口。
