# 帮助与物品引用

说明中的帮助主题和物品名称可以打开参考阅读器。冒险工具与背包、任务、技能等界面使用相同的说明链接规则。

## 帮助主题

点击帮助链接（TIPBOX）后，阅读器显示主题、正文和资料中的配图。多页帮助可以切换页面；继续点击其中的帮助或物品链接后，使用标题栏的返回按钮回到上一页，并保留页码和阅读位置。关闭按钮退出阅读器。

电脑上的阅读器采用冒险工具的浅色样式，返回位于标题下方工具栏，关闭位于右上角。手机和平板按屏幕适配标题、按钮和内容高度，返回与关闭位于标题栏右侧。长内容在阅读器内滚动。

帮助中的地点和魔物链接沿用[导航规则](./navigation)：只查看地图或图鉴后关闭，可以回到帮助的原阅读位置；开始寻路或发出传送请求后，不再自动返回。

## 物品引用

ITEM、ITEMLINK 和技能说明中的物品引用会显示为可点击的物品名称。在参考阅读器中查看说明后，可以返回前一篇帮助或物品资料。没有对应物品资料时，保留名称文字。

查看物品引用不会使用、购买、获得或装备该物品。聊天中由玩家发送的物品链接仍使用聊天自己的物品查看窗口。

## 网页与文字样式

网页链接（URL）在浏览器新标签页打开 HTTP 或 HTTPS 页面，游戏中的来源窗口保留。无法使用的地址只保留文字。

FONT、粗体和斜体等标签只负责颜色、字号与排版，没有独立操作。字号会适应手机和平板；INFO 是链接目标数据，不是可点击功能。说明中原本作为文字使用的 `<Enter>`、`<Zzz>` 等内容仍按文字显示。
