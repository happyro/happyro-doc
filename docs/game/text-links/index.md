# 说明链接与帮助

NPC 对话、任务、物品、技能和冒险工具的说明中，部分文字可以打开地图、图鉴或帮助。电脑点击与手机、平板轻触使用相同规则。

| 说明内容 | 点击后的功能 | 详细说明 |
| --- | --- | --- |
| 地点或 NPC 名称（NAVI） | 保存 NPC 对话中的导航目标，或直接打开地图标点 | [地图与目标链接](./navigation) |
| 魔物目标（NAVI） | 在普通说明中打开魔物图鉴，查看出现地图 | [地图与目标链接](./navigation) |
| 帮助主题（TIPBOX） | 打开帮助阅读器，可翻页和返回 | [帮助与物品引用](./help) |
| 物品名称（ITEM、ITEMLINK） | 在参考阅读器中查看物品说明 | [帮助与物品引用](./help) |
| 网页链接（URL） | 在浏览器新标签页打开网页 | [帮助与物品引用](./help#网页与文字样式) |
| 颜色、字号、粗体或斜体（FONT 等） | 只改变文字样式，没有点击操作 | [帮助与物品引用](./help#网页与文字样式) |

这里的 NAVI、TIPBOX 等是资料标签的名称，正常阅读时看到的是地点、物品或主题文案。INFO 保存链接使用的内部目标，不会作为正文或按钮显示。

没有可用目标或缺少对应资料时，文案保留为普通文字。文字有颜色不一定表示可以点击；实际是否能传送、使用物品或完成任务，仍由服务器按角色当前状态判断。
