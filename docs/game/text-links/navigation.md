# 地图与目标链接

NAVI 是说明中的地点或目标链接。有可用坐标并支持传送的目标可以点击；普通说明中的魔物链接在有对应图鉴结果时可以点击。链接可用不表示该位置当前一定有目标 NPC 或存活的魔物。

## NPC 对话中的导航

1. 点击对话里的地点链接，会短暂提示「已加入导航，结束对话后可传送。」
2. 继续并正常结束对话。点击链接本身不会替你回答 NPC，也不会中断任务或发放奖励。
3. 对话结束后，在右下角点击黄色的「打开地图」按钮查看标点；不再需要时点击「取消」。这两个按钮独立显示，显示期间隐藏战斗信息。

对话里连续点击多个地点，只保留最后选择的目标。再次开始对话时入口暂时隐藏，结束后再显示；打开地图、取消或断线会清除待打开的目标。

## 任务、物品与冒险工具中的导航

在任务说明、任务追踪、物品说明、装备比较以及冒险工具等普通说明中，点击坐标链接会直接打开冒险工具地图并标点；点击魔物目标会打开魔物图鉴及其分布资料。点击文字本身不会立即传送。

原窗口会暂时隐藏，并保留选中项和滚动位置。只查看地图或图鉴后关闭，会回到原窗口；开始寻路或发出传送请求后，原窗口不再自动打开。本地条件不满足、传送请求没有发出时，仍可关闭地图返回。

交易、商店、附魔、精炼、材料确认和选择等操作窗口中的导航只显示文字。即使从这些说明进入帮助或物品参考，也不能通过里面的导航跳出当前操作流程。

## 地图中的操作

地图沿用[冒险工具](/game/adventure-tools)的普通操作：

- 同地图目标可使用寻路，开始行走后地图保持打开。
- 不同地图不能直接寻路；支持传送且满足当前条件时，可以使用传送。执行传送会关闭地图。
- 关闭只退出当前地图，不会自动执行寻路或传送。

传送成功不额外显示成功提示；失败、超时或到达结果无法确认时仍会提示原因。导航不会自动完成任务步骤、NPC 对话或领取奖励。
