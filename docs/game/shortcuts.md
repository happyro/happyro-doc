# 快捷键与技能

快捷栏用于手动施放技能和使用物品；自动战斗的攻击方式在[战斗设置](/game/combat)中单独选择。

## 手机和平板配置

点击游戏右下角“快捷键”，或从“菜单 → 快捷键”进入。每页展示六个位置，可使用翻页箭头切换。

![99 级剑士罗安的平板快捷键配置](/images/game/controls/tablet-shortcuts.png)

1. 在上方选择要修改的位置。
2. 用技能类型、物品类型筛选列表，点击技能或道具查看说明。
3. 技能使用“施放等级”选择已学范围内的等级；物品不需要设置等级。
4. 点击“保存”。删除绑定使用“清空位置”。

说明顶部显示“当前位置 X”，保存前核对位置和技能名称。物品显示图标及说明，数量以背包为准。改变绑定不等于立即使用物品或施放技能。

手机竖屏将说明与候选列表上下排列，位置选择和保存操作保留在底部。

## 电脑快捷栏

电脑使用桌面快捷栏绑定技能与道具。打开技能或背包窗口，将可用技能／道具放入快捷位置；具体按键以快捷栏显示为准。触屏与桌面的栏位展示方式不同，修改前检查当前页和位置。

## 学习与升级

从技能窗口查看说明、前置条件、已学等级和剩余技能点；学习或升级会交给服务器检查。快捷键列表只提供当前能绑定的条目，未学会技能不会因绑定而解锁。重置技能点属于独立操作，不用于调整快捷键。
