# 快捷键与技能

快捷栏用于手动施放技能和使用物品；自动战斗的攻击方式在[战斗设置](/game/combat)中单独选择。

## 手机和平板配置

点击游戏右下角“快捷键”，或从“菜单 → 快捷键”进入。每页展示六个位置，可使用翻页箭头切换。

![99 级剑士罗安的平板快捷键配置](/images/game/controls/tablet-shortcuts.png)

1. 在位置选择区选择要修改的位置。
2. 用技能类型、物品类型筛选列表，点击技能或道具查看说明。
3. 技能使用“施放等级”选择已学范围内的等级；物品不需要设置等级。
4. 点击“保存”。删除绑定使用“清空位置”。

未选候选时，说明提示「选择技能或道具，保存到位置 X」。保存前核对当前选择的位置和技能名称。物品显示图标及说明，数量以背包为准。改变绑定不等于立即使用物品或施放技能。

手机竖屏将说明与候选列表上下排列，位置选择与翻页按钮移到列表下方；保存操作位于底部。平板和手机横屏的位置选择位于面板上方。

## 电脑快捷栏

电脑使用桌面快捷栏绑定技能与道具。打开技能或背包窗口，将可用技能／道具放入快捷位置；具体按键以快捷栏显示为准。触屏与桌面的栏位展示方式不同，修改前检查当前页和位置。

## 学习与升级

从技能窗口查看说明、前置条件、已学等级和剩余技能点。手机和平板选中技能后点击「学习一级」或「升级一级」，核对目标等级并确认；每次提升一级，等待服务器更新后再继续。快捷键列表只提供当前能绑定的条目，未学会技能不会因绑定而解锁。重置技能点属于独立操作，不用于调整快捷键。

物品的使用、穿戴和转职后的资格变化见[背包与装备](/game/inventory-equipment)；快捷栏不会改变物品数量或装备资格。

## 手动施放与绑定的区别

手机和平板在技能窗口选中已学主动技能，点击「设置快捷键」，选择施放等级和位置并确认；关闭面板后点击对应快捷格施放。需要目标的技能还要点击目标，地面技能需要选择落点，自用技能直接作用于角色。被动技能用于查看说明，不能作为主动技能绑定和施放。

升级技能前核对前置和剩余点数，提交后等待服务器更新。「重置技能点」会改变技能学习状态，需要权限和确认，不用于清空某一个快捷栏位置。
