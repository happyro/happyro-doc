# 专用窗口附魔

核对日期：2026-10-29。统计口径与验证范围见[附魔与升阶总览](/game/equipment-services#数量汇总)。

这是与精炼／升阶并列的装备附魔窗口。装备目录里有配方，但正式 NPC 没有入口的条目，不计入这里的可用清单。

## 入口与操作

- **OS 武器附魔**：雷根修芦附设研究所 `rgsr_in`，附魔研究员（托鲁斯），坐标 `112,167`。当前通过资料与穿戴核验的是绿光拳刃-OS-AD，要求等级 170、刺客系；表中以暗影十字验证穿戴。
- **灰狼防具附魔**：灰狼村 `wolfvill`，艾梅特，坐标 `164,137`。需要完成对应 EP18 主线进度后才出现兑换与附魔菜单；未完成前只有任务对话。不同部位对应不同附魔配方。

手机／平板选择装备，通过底栏“方式”选择可用附魔，阅读材料、余额及成功率，点击“下一步”核对后确认。桌面选择装备与普通／完美／升级／重置页签，再选择目标并执行。结果返回后重新与 NPC 对话才能继续。

指定附魔、随机附魔、升级和重置的材料与费用不同。重置会清除对应附魔，不能把重置当作免费重新选择。
