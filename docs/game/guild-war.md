# 攻城战

攻城战通过普通地图入口或攻城旗帜进入。进入资格、开放时段、职业限制和当前攻城状态由服务端检查；无法进入时按窗口提示处理。

## 三种攻城类型

| 类型 | 说明 |
| --- | --- |
| FE | 传统攻城战，包含城堡争夺和公会战斗 |
| SE | 防御设施、守护石和占城相关内容，按既定攻城时段开放 |
| TE | 训练攻城战，部分职业不能进入，入口会显示限制原因 |

## 进入和队伍协作

从地图入口步行或通过对应旗帜进入。联盟、敌对公会和非公会角色的进入结果可能不同；邀请和授权必须在当前攻城状态下有效。进入前确认角色职业、所属公会和当前攻城时段。

## 城堡设施与管理

拥有相应权限的公会成员可以使用城堡管理、投资、守护石和修复等功能。修复设施需要满足材料和权限条件；普通成员或非本公会角色看到入口，也不代表可以执行管理操作。

## 开放时段和限制

攻城结束后，场内状态和待处理请求会按服务器规则清理。SE 按既定周二、周四 18:00—20:00 时段判断；TE 的职业限制以入口提示为准。具体规则可能随当前服务器设置变化，进入时应以游戏内提示为准。

公会成员、职位、仓库和权限说明见[公会与氏族](/game/guild)。
