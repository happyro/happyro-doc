# 邮件与附件

手机和平板从“菜单 → 邮件”进入。邮件是独立的收发功能，不等同于聊天中的私聊；私聊操作见[聊天与社交](/game/social)。

## 阅读与领取

选择邮箱分类，可按标题或寄件人搜索，搜索不区分大小写。点击邮件后查看正文，黄色标题栏右侧显示寄件人；“金额与物品”标题右侧显示附加金额。

![罗安查看邮件正文和物品附件](/images/game/mail/tablet-mail-read.png)

“领取金额”和“领取物品”分别操作对应附件。领取前预留背包容量与负重，操作结果以服务器回复为准；不能仅凭打开邮件就认为附件已经领取。

## 写信

1. 点击“写信”，填写收件人角色名并点击“校验”。
2. 填写标题和正文，需要附加金额时填写 Zeny。
3. 从背包列表选择附件物品，输入数量；已添加的附件可用“移除”取消。
4. 点击“发送邮件”，核对收件人后确认，等待服务器结果。

![写信右侧将表单与附件分为上下等高区域](/images/game/mail/tablet-mail-compose.png)

手机和平板的收件人、标题、正文与 Zeny 标签位于输入框上方。写信内容与附件各占右侧区域的一半，分别滚动；表单显示不全时在上框内滚动，下框内查看和移除附件。

最多添加五种附件，物品限制、金额和邮费以服务器校验为准。余额需同时覆盖附加金额与邮费；发送失败时先根据提示检查收件人、物品和余额。
