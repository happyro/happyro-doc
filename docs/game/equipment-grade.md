# 装备升阶

核对日期：2026-10-29。统计口径与验证范围见[附魔与升阶总览](/game/equipment-services#数量汇总)。

在 `grademk` 的史拉托斯（`34,184`），或 `paramk` 的舒莉贝（`34,184`）选择“装备升阶”。操作与布局见[背包与装备](/game/inventory-equipment#装备升阶)。

当前规则针对允许升阶的 **5 级武器和 2 级防具**，并不包含所有同等级装备。默认从无阶级升至 D，再依次升至 C、B、A；A 已是最高阶级。各阶段需重新达到对应精炼条件；成功升阶会将精炼归零，因此刚升到 D 的装备不能直接照搬上一次精炼条件继续。

初次升阶的默认规则从精炼 +9 开始有成功率。具体材料、祝福上限、费用、失败后果和实际成功率以当前窗口为准；管理员可调整全服概率，见[精炼／升阶设置](/admin/game-settings#精炼-升阶)。
