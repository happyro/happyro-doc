# 任务与目标

电脑使用任务入口或 Alt + U；手机和平板点击左上角「任务」，也可从菜单进入。各职业的具体条件、材料和路线见[转职攻略](/strategy/job-change/)。

## 查看任务进度

手机／平板可以筛选「全部任务」「进行中」「已暂停」「已完成」。选择任务后查看摘要、说明、狩猎目标和已完成／所需数量；有截止时间、道具奖励或经验信息时也会列出。

任务说明来自客户端资料，任务状态和狩猎计数由服务器同步。图鉴里的同名魔物不一定符合任务要求，应同时核对副本、地图、任务阶段和目标身份。没有当前任务时，不能仅靠打开面板获得任务。

## 暂停与启用

选中进行中任务后可点「暂停任务」，已暂停任务可点「启用任务」，等待服务器确认后再检查分类与状态。已完成任务不能通过此按钮重新开启。

这里的暂停不是放弃或删除任务，也不承诺暂停任务的实际截止时间。限时任务和重新领取条件以对应 NPC 及服务器规则为准。

## 查看地图与寻找目标

带导航目标的任务可通过「查看地图：…」按钮查看位置；任务说明和追踪中的可点击地点文字也会打开地图标点，魔物目标链接则打开魔物图鉴。只查看后关闭，会恢复原任务窗口；开始寻路或发出传送请求后不再自动返回。详见[地图与目标链接](/game/text-links/navigation)。

没有导航资料的任务不会自动产生路线；查看地图也不会替你完成对话、领取奖励或跨地图传送。

魔物名按同 ID 来源审定。标准目标的封包短名会恢复为已核实的完整中文；通用种族条件、特殊剧情称呼和考试干扰项保留各自含义。遇到名称冲突时记录任务标题、目标、地图和进度截图，避免只按近似名称寻找目标。
