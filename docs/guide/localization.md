# 关于汉化

HappyRO 的中文内容覆盖常用界面、物品、技能、魔物、地图、系统消息与 NPC 对话。不同文字来自客户端代码、服务端脚本和运行资源，实际范围以当前版本为准。

NPC 名称同时核对场景显示、对白标题、正文称谓、选项、任务和导航。经典修炼场、沉船学院、杜兰出生与后续转职已按当前脚本复审；同一人物统一称呼，剧情化名、不同人物共用的职务名称及故意设置的考试干扰选项按上下文保留。任务要求手工输入的口令，需按提示保留标点。

## 玩家遇到未翻译内容

记录所在地图、NPC 或物品／技能名称、操作入口及原文截图，再通过[联系与反馈](/community/contact)报告。某些文字只有触发特定对话或剧情后出现，提供前置步骤更容易复现。

客户端界面和资源更新后需要重新加载；服务端对话则可能需要更新相应脚本。不同来源的译文不能只靠刷新网页全部修复。

## 维护方式

产品译文直接维护在客户端、服务端等所属仓库，不使用旧翻译分片合并回写流程。修改时区分玩家可见文本与程序标识，检查编码、占位符和脚本语法，并在实际游戏中验证。

部分 kRO 文字保存在 LUB 文件中。回编译源位于根仓库 `localization/sources/kro-20211105/`，按目标 Lua 5.0 或 5.1 版本编译和语义校验后安装到运行目录；经过核验的官方源材料不修改。图片文字、特殊编码和资源覆盖优先级需要分别处理。

## 贡献翻译

先按[开发指南](/development/)确认内容所属仓库。自动翻译和批量检查可以辅助维护，但不能替代中文审读与实际显示验收；不要翻译程序键名、资源路径或脚本参数中的固定标识。提交规则见[贡献指南](/development/contributing)。
