# 账号与角色

从“用户管理”进入账号、角色或登录记录列表。先搜索并选择目标，再查看详情和当前可用操作。

## 核对目标

角色名、角色 ID、所属账号、职业及在线状态用于识别目标。相似名称或同一账号的多个角色需要特别核对；账号操作与角色操作影响范围不同。

## 账号操作与游戏 GM

账号列表每行的「操作」按钮带编辑图标和下拉箭头。菜单按权限提供修改邮箱、重置密码、设置游戏 GM、封禁／解禁及删除；工具栏提供注册和批量操作。

设置 GM 时，先核对弹窗中的账号与当前权限组，再选择「普通玩家」或「游戏管理员 GM」并保存。需要后台的玩家查看及 `players.gm` 权限；游戏 GM 作用于该账号下全部角色，不会赋予管理后台权限。

保存后完整退出游戏并重新登录才生效，仅切换地图不更新已有会话权限。未改变选择时不能重复保存；若提示权限组已经变化，刷新并重新核对目标。

## 角色维护

点击角色行的「角色属性」按钮，在同一弹窗通过职业、等级与点数、基础属性、四转特性、技能、状态恢复六个 Tab 连续操作。按钮与账号操作使用相同的描边和编辑图标；角色功能直接打开弹窗。

根据权限维护角色属性和状态。在线维护需要游戏控制服务响应，失败时读取结果，不把前端表单值当作服务端已经生效的值。角色在游戏中进行交易、对话或其他受限动作时，相关维护可能被拒绝。

游戏内“冒险工具 → 角色”也提供部分维护入口，仍由服务端检查权限；普通玩家的职业外观操作见[职业外观](/game/appearance)。

## 登录记录

登录记录用于排查连接和账号使用问题。对外反馈时只提供必要字段，避免发布账号凭据、个人信息或完整数据库记录。物品与 Zeny 操作见[运营发放](/admin/grants)。
