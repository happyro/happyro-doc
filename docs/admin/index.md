# 管理后台

HappyRO Admin 是独立的管理应用，面向服务器管理员。可以先体验[后台演示](https://happyro-admin.kugarocks.com)，自己的环境入口由部署时的公开地址决定。

## 登录与权限

后台不开放公开注册。空数据库首次初始化的账号见 [Docker 安装](/deploy/docker#默认账号)。后台账号和游戏账号属于不同用途，不能将游戏登录凭据直接当作后台账号。

菜单与操作受后台权限和游戏服务状态限制；执行后检查提示和记录，不能仅凭按钮点击判断已成功。

## 常用操作

- [账号与角色](/admin/accounts-characters)：查询账号、角色与登录记录。
- [运营发放](/admin/grants)：向指定角色发放物品或 Zeny，核对执行记录。
- [游戏设置](/admin/game-settings)：经验、掉落、精炼与冒险工具权限。
- 游戏资料菜单查询物品、魔物、NPC 和地图；自定义资料刷新见[自定义功能](/deploy/customization)。

服务部署、数据备份和恢复属于[部署与运维](/deploy/)，不要在后台操作说明中寻找数据库恢复步骤。
