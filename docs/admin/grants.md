# 物品与 Zeny 发放

::: info 适用版本
本页按当前主分支说明，包含 v0.5.0 开发中功能；已发布离线包以[下载页](/guide/downloads)与对应版本说明为准。
:::

从“运营管理”选择物品发放或 Zeny 发放；查看结果时进入发放记录。操作需要相应后台权限。

## 发放步骤

1. 搜索目标角色，核对角色名和 ID。
2. 物品发放时搜索物品并核对 ID、数量及界面提供的附加字段；Zeny 发放时核对金额。
3. 检查确认信息后提交，等待服务端结果。
4. 在记录中核对执行状态，再让角色检查实际获得内容。

网络超时不一定表示未执行，不应直接重复发放。先查记录和角色实际数据，再决定是否需要重试。不同物品的叠加、装备属性与发放限制以服务器检查和界面可用字段为准。

## 资料与结果

物品图鉴用于查询，发放是会改变角色资产的管理操作。自定义物品需要先正确加载服务端数据库并刷新目录；名称或图标正常显示不代表所有物品效果已经通过验收。
