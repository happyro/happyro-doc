# 共用转职流程

[返回职业线选择](index.md)。本页集中说明一转入口、转生、进阶二转和四转条件；二转考试与三转任务见各职业线攻略。

适用于 **HappyRO v0.5.0**，扩展职业不在本页范围内。

## 出发前

- Base 是基础等级，Job 是职业等级。转职前先分配剩余技能点，检查负重与背包空间。
- 各攻略采用已核对的任务路线；二转通常按 Job 50 准备，三转按进阶二转 Base 99 / Job 70 准备。这是完整路线的准备建议，不替代各 NPC 的最低报名条件。
- 地图代码与坐标用于定位 NPC，例如 `prontera 153,193` 表示该地图的 `(153,193)`。走到旁边可通行格交谈；剧情触发点需要正常走入。
- 普通地图赶路可使用已开放的导航，考试中的步行、杀怪、倒计时与剧情不能靠传送跳过。聊天室等候室通常需要双击加入。
- 材料清单、问答题、课程与部分奖励随机。本页写明「示例」的内容仅是一条已核对路线；不是每个角色都拿相同材料。
- 战斗考试按自己的职业准备装备、技能与回复用品。原流程验证使用过测试属性和材料准备，本文不把它们当作玩家条件或最低补给标准。

## 转生与进阶二转

普通二转 → 高阶初心者 → 高阶一转 → 进阶二转，然后再进入各线三转。

1. 普通二转达到 **Base 99 / Job 50**，用完技能点，准备 **1,285,000 Zeny**。
2. 到 `yuno_in02 88,164` 找图书馆的 Metheus Sylphe 捐赠，再阅读 `yuno_in02 93,207` 的伊米尔之书。
3. 到 `yuno_in05 49,43` 找伊米尔之心，经 NPC 进入英灵殿。
4. 在与女武神对话前将**负重与剩余 Zeny 清零**，解除手推车、骑乘和猎鹰；有价值的物品先存仓，金币按可用渠道妥善保存，不必丢弃装备。
5. 找 `valkyrie 48,86` 女武神完成转生，成为 Base 1 / Job 1 的高阶初心者，技能重置并领取重生礼物。
6. Job 10、完成基础技能后，回原一转导师办理高阶一转。
7. 练到 Job 50、用完技能点，再经伊米尔之书进英灵殿，找各职业线指定导师成为进阶二转。各线坐标见对应攻略。

有过伊米尔之书访问资格的角色，按 NPC 当前对话继续；不要把一次历史访问状态当作所有新角色免捐款的规则。

## 四转条件

本组十三个分支共用普隆德拉 `prontera 153,193` 的「四转职业导师」。

| 条件 | 要求 |
| --- | --- |
| 当前职业 | 经转生路线取得的对应进阶三转职业 |
| 基础等级 | Base 至少 200 |
| 职业等级 | Job 至少 70 |
| 剩余技能点 | 0 |
| 操作 | 阅读说明，选择「确认四转」 |

转职后保留基础等级，Job 从 1 开始，开放特性属性与 AP；不再适用的装备和状态按职业规则处理。这是 HappyRO 自定义流程，不是其它 RO 版本的通用四转任务。

## 卡住时先检查

- **无法报名或转职**：检查当前职业、Base／Job、未分配技能点、负重及奖励空间，关闭上一段对话后再交谈。
- **走到坐标没有剧情**：先走离触发区，再普通步行进入；部分事件需要先完成前置对话。
- **交材料仍被拒绝**：核对物品 ID、数量、任务击杀计数，以及是否仍佩戴任务要求交回的装备。
- **考试超时**：按入口 NPC 指引重试，处理旧任务物品和负重；不要直接修改职业或任务变量，否则可能无法继续。
- **刺客三转等待**：保留原任务等待。三小时等待在既有测试中使用了加速，游戏本身仍要求等待，不把测试加速当作玩家操作。
