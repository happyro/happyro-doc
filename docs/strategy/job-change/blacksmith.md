# 铁匠系转职攻略

**商人 → 铁匠 → 神工匠 → 机甲神匠 → 机甲大师**

[转职总览与共用流程](index.md)。本文按 HappyRO 当前 v0.5.0 开发版本整理；该版本尚未发布，旧版本可能缺少相关任务修复。

## 一转：商人

职业等级 Job 10、完成基础技能后，前往 `alberta_in 53,43`。找公会职员曼苏，选择「我想成为商人」并完成对话。当前 Renewal 路线不需要旧版送货考试。

1. 找 `ein_in01 18,28` 公会导师报名，按指引完成知识考试。
2. 到 `ein_in01 201,27` 领取并交付随机材料。已记录的一组是铁 1、绿色药草 1、动物皮 2、环首刀 [2] 1；实际以 NPC 清单为准。
3. 将 NPC 制作的武器送给指定收件人。已记录路线为 `hugel 168,183` 的 Bismarc，选择「我确定就是这把」，领取配送收据；不要误选自己使用的武器。
4. 回 `ein_in01 201,27` 交收据，再回 `18,28` 公会导师。
5. 找 `ein_in01 24,41` 参加最终五题知识考试，取得铁匠的锤子，再回公会导师成为铁匠。

问答及配送对象可能不同，按当前题目和任务指引处理，不把一次材料分配视为全部路线。

## 转生与进阶二转：神工匠

按[共用转生流程](index.md#转生与进阶二转)成为高阶初心者。Job 10、完成基础技能后回 `alberta_in 53,43`，办理高阶商人。

练到 Job 50 并用完技能点，再阅读 `yuno_in02 93,207` 的伊米尔之书进入英灵殿，找 `valkyrie 44,50` 的神工匠导师，选择「是」完成进阶二转。这里采用 Job 50 的完整路线，不表示所有分支都必须到这个等级才允许报名。

以下按神工匠 Base 99 / Job 70、用完技能点的路线整理。准备战斗补给并留出奖励栏位；特别要求零负重的阶段先存仓，再按 NPC 要求领取考试物品。

1. 找 `yuno 129,156` Chainheart 报名，再找 `jupe_cave 37,55` 学者，经 NPC 传送进入 `jupe_core2`。
2. 依次找 `149,273` 第一位灵魂、`53,75` 第二位灵魂、`242,62` 第三位灵魂，按提示专注聆听。
3. 依次步行到 `29,150`、`272,149`、`288,142`、`149,34`，触发机关和知识对话。机关存在时限，普通地图导航不能替代试炼触发。
4. 沿途清理迪靡克并准备回复用品。回 `149,273` 第一位灵魂完成对话，传回朱诺。
5. 再找 Chainheart，成为机甲神匠。

## 四转：机甲大师

以经过转生的机甲神匠达到 **Base 200 / Job 70**，用完剩余技能点，前往 `prontera 153,193` 找「四转职业导师」，选择「确认四转」。转为机甲大师后保留基础等级，职业等级从 1 开始，开启四转特性与 AP。

这些是 HappyRO 当前自定义四转条件；未经过转生的普通三转不适用本路线。更多说明见[四转条件](index.md#四转条件)。
