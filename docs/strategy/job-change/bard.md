# 诗人系转职攻略

**弓箭手 → 诗人 → 搞笑艺人 → 宫廷乐师 → 天籁颂者**

[转职总览与共用流程](index.md)。本文按 HappyRO 当前 v0.5.0 开发版本整理；该版本尚未发布，旧版本可能缺少相关任务修复。

## 一转：弓箭手

职业等级 Job 10、完成基础技能后，前往 `payon_in02 64,71`。找弓箭手导师申请转职，完成对话并领取新手弓及箭筒。当前 Renewal 路线不需要旧版木材收集考试。

男性弓箭手走诗人分支；女性分支见[舞娘系](dancer.md)。

1. 找 `comodo 226,123` 流浪诗人拉洛，先请他唱歌并称赞，再次交谈表达想成为诗人。交 NPC 接受的花；已记录路线使用希纳雷花 1 个。
2. 完成姜饼城雪人支线，顺序见下表。
3. 回拉洛跟唱，按当前歌的原句逐行输入，注意中文标点。歌曲随机，不要把一首歌的答案用于所有题目。
4. 选择「请直接帮我转职吧」可直接完成诗人转职；木材换武器是可选奖励，本攻略不展开该支路。

| 顺序 | 地点与操作 |
| --- | --- |
| 1 | `xmas_in 167,173` 达弗尔 → `xmas 134,112` 雪雪 → `xmas 117,304` 波泽 |
| 2 | `xmas 176,236` 坎塔塔，交墨汁、黏稠液体各 1 个 |
| 3 | `xmas_in 27,103` 阿姨 → 回雪雪领取盐 → 回阿姨 |
| 4 | `xmas 146,136` 小丑询问雪雪 → `206,168` 男孩与 `208,168` 女孩 |
| 5 | 回雪雪领取礼物，再返回拉洛 |

若抽到「布拉基」，已核对的六行是：

```text
布拉基，布拉基，
永远呼唤诗人的名字。
我的歌是他的呼吸，
我的心是他的意志，
所有流浪诗人都是他的子民，
一切赞美都归于他。
```

## 转生与进阶二转：搞笑艺人

按[共用转生流程](index.md#转生与进阶二转)成为高阶初心者。Job 10、完成基础技能后回 `payon_in02 64,71`，办理高阶弓箭手。

练到 Job 50 并用完技能点，再阅读 `yuno_in02 93,207` 的伊米尔之书进入英灵殿，找 `valkyrie 53,54` 的搞笑艺人导师，选择「是」完成进阶二转。这里采用 Job 50 的完整路线，不表示所有分支都必须到这个等级才允许报名。

以下按搞笑艺人 Base 99 / Job 70、用完技能点的路线整理。准备战斗补给并留出奖励栏位；特别要求零负重的阶段先存仓，再按 NPC 要求领取考试物品。

1. 找 `alberta 196,133` 卡里安帮忙，到普隆德拉 `141,97`、`140,331`、`146,218` 三位 NPC 处调查，再返回卡里安。
2. 前往飞艇 `airplane 222,67`，再到胡格尔旅馆 `hu_in01 267,5`、酒吧 `hu_in01 361,103`；选择「继续听」，再次交谈听「金属之声」，回旅馆推进。
3. 到 `tha_scene01 140,200` 触发收据剧情，再找 `yuno 143,170` 克里克先生取得照片，领取击杀三十三只玩偶熊的任务。
4. 在 `ein_fild03` 完成狩猎，再找 `lighthalzen 155,119` 的女孩交付。
5. 到 `ice_dun01 157,15` 开始十二段诗句剧情，逐页读完自动传送中的对话，到达拉赫旅馆后先完成醒来剧情，再找 `ra_in01 358,130` 老妇人问船只线索。
6. 到 `ve_fild07 131,132` 公告牌，选择「乘独木舟」，途中连续按提示「把水舀出去」，完成漂流及上岸剧情。
7. 找 `comodo 192,119` 独木舟高手，再找 `159,316` 烤肉的女人。去 `moc_fild16 206,232` 触发沙漠纸条并接受同行，再到 `aldebaran 140,130` 听钟楼故事。
8. 回 `prontera 155,40`，沿 `155,42 → 155,44 → 155,46 → 155,48` 完成自动传送剧情，进入 `prt_in` 后找 `94,172` 卡里安，成为宫廷乐师。

连续剧情需读完每页。既有记录曾在末页出现无按钮，正常返回选角再进入后可继续；该现象尚未确认根因，遇到时先保留当前任务状态，不要重置任务。

## 四转：天籁颂者

以经过转生的宫廷乐师达到 **Base 200 / Job 70**，用完剩余技能点，前往 `prontera 153,193` 找「四转职业导师」，选择「确认四转」。转为天籁颂者后保留基础等级，职业等级从 1 开始，开启四转特性与 AP。

这些是 HappyRO 当前自定义四转条件；未经过转生的普通三转不适用本路线。更多说明见[四转条件](index.md#四转条件)。
