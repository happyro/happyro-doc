# 转职攻略总览

本分类按**职业线**组织：每篇从一转讲到四转，中间包含转生和进阶二转。十二条主职业线中，诗人、舞娘任务分别成文，共十三个分支，方便按自己的角色路线查找。

攻略根据 2026-10-18 完成的原生 NPC 流程记录及当前脚本整理，适用于 **HappyRO v0.5.0**。旧版可能缺少任务修复；扩展职业不在本组攻略范围内。

## 从哪里开始

- **第一次转职**：先看[准备事项与一转入口](common.md#出发前)，再选择自己的职业线。
- **已经二转，准备转生**：直接查看[转生与进阶二转](common.md#转生与进阶二转)。
- **已经进阶三转，准备四转**：查看[四转条件与导师位置](common.md#四转条件)。
- **任务中途卡住**：先查[通用排查](common.md#卡住时先检查)，再对照职业线中的当前步骤。

**完整顺序：初心者 → 一转 → 二转 → 转生 → 高阶一转 → 进阶二转 → 三转 → 四转。** 下表省略共用的转生段，具体攻略中会逐步说明。

## 使用定位图

各职业线的二转、三转章节都有入口定位图，共用 NPC 位置见[共用流程](common.md)。红点标出 NPC 或剧情触发点，浅色为可通行区域；点击可放大。室内地图可能包含多个房间，应沿入口和实际道路前往，不能把图上的直线距离当作路线。

## 适用范围

材料组合、问答题和部分课程会随机变化，示例只适用于相同任务分支。攻略以已完成的 NPC 主路线为基础，战斗补给按自己的角色准备；完整证据及未覆盖范围见[流程记录](https://github.com/happyro/happyro/blob/main/docs/development/job-change-review/README.md)。
