# 刺客系转职攻略

**盗贼 → 刺客 → 十字刺客 → 十字斩首者 → 暗影十字**

[转职总览与共用流程](index.md)。本文按 HappyRO 当前 v0.5.0 开发版本整理；该版本尚未发布，旧版本可能缺少相关任务修复。

## 一转：盗贼

职业等级 Job 10、完成基础技能后，前往 `moc_prydb1 39,129`。找盗贼向导，选择「我想成为盗贼」并确认；再找同地图 `42,133` 的公会成员办理仪式。当前 Renewal 路线不需要旧版蘑菇收集考试。

1. 盗贼用完技能点后，找 `in_moc_16 19,33` 公会成员报名，完成笔试并按考官指引进入实战。
2. 经过 `211,61` 的提醒位置，找 `211,62` 考官进入等候室。考试中只击杀六个名字为「转职目标」的目标，避开陷阱。
3. 门打开后到 `87,137` 附近进入下一关，再到 `89,98` 听说明。接下来**不击杀怪物**，走到 `87,49` 完成生存考试。
4. 在 `182,169` 附近接受迷宫引导，关闭提示后沿通路走到 `149,80` 的公会长处。
5. 完成问答并领取武器与无情之心，返回入口找 `19,33` 的公会成员，成为刺客。

## 转生与进阶二转：十字刺客

按[共用转生流程](index.md#转生与进阶二转)成为高阶初心者。Job 10、完成基础技能后回 `moc_prydb1 39,129`，办理高阶盗贼。

练到 Job 50 并用完技能点，再阅读 `yuno_in02 93,207` 的伊米尔之书进入英灵殿，找 `valkyrie 44,58` 的十字刺客导师，选择「是」完成进阶二转。这里采用 Job 50 的完整路线，不表示所有分支都必须到这个等级才允许报名。

以下按十字刺客 Base 99 / Job 70、用完技能点的路线整理。准备战斗补给并留出奖励栏位；特别要求零负重的阶段先存仓，再按 NPC 要求领取考试物品。

### 调查与第一次等待

1. 找 `que_job01 75,96` 阿卡特接受秘密委托，按指引前往菲音斯的公会。找 `job3_guil01 82,95` 道拉接洽，再找 `16,20` 梅谢尔接受调查。
2. 按任务日志调查本地人物：酒馆 `ve_in 228,108` 的女服务员、`ve_in 246,303` 的年轻商人、`veins 291,215` 的警戒员。读完对话并核对收集的情报；需要线索时可再问道拉。
3. 继续询问 `veins 187,143` 商贩和 `235,126` 老人，再找 `223,180` 梅丽莎。描述目标为女孩、淡黄色头发、年轻人，取得艾丝缇尔达的行踪。
4. 等待任务计时到期，再到 `veins 337,284` 附近触发伏击，选择突袭、审问并安抚艾丝缇尔达。当前任务等待为五十分钟；NPC 口头描述可能使用约一小时，以任务计时为准。

### 三小时等待与仓库

1. 回 `job3_guil01 82,95` 道拉处，再找 `79,15` 艾丝缇尔达，询问经历与送货安排，开始三小时等待。
2. 到期前仓库会提示「距离约定时间还早」。**正常玩法需要等待三小时**；既有审计只验证了提前拒绝和到期通行，没有自然等待满三小时，不代表游戏缩短了时限。
3. 到期后走到 `veins 206,56`，选择「进去」。在 `job3_guil02 51,43` 附近触发黑衣男子剧情并击败蒲公英。
4. 战后立即找 `49,43` 的蒲公英读完剧情，领取宅邸钥匙（6150）并离开；领取钥匙有时限，不要停留。

### 最终宅邸

1. 带钥匙找 `rachel 115,77` 吉尔克，再找 `ra_in01 175,196` 奥蕾莎，询问钥匙与主人。回 `job3_guil01 16,20` 梅谢尔交钥匙，领取最后行动。
2. 找 `ve_fild02 330,384` 伦扎克进入宅邸，任务限时十分钟。到 `job3_guil03 55,79` 铁丝网选择「钻进空隙」，沿路清理守卫。
3. 找 `111,51` 拉赫祭司，读完对话并击败其怪物形态。战后立即找 `146,70` 伦扎克撤离，不能在战后窗口中拖延。
4. 回梅谢尔汇报，再找 `job3_guil01 148,53` 贝尔卡塞尔，选择「我想成为十字斩首者」→「是，转职」，读完尾声成为十字斩首者。

## 四转：暗影十字

以经过转生的十字斩首者达到 **Base 200 / Job 70**，用完剩余技能点，前往 `prontera 153,193` 找「四转职业导师」，选择「确认四转」。转为暗影十字后保留基础等级，职业等级从 1 开始，开启四转特性与 AP。

这些是 HappyRO 当前自定义四转条件；未经过转生的普通三转不适用本路线。更多说明见[四转条件](index.md#四转条件)。
